Field notes.
Best practices
  • New connector → leave it in Dry-run, hit Test, read the response, then flip Live.
  • Set focus arcs before running Standup / Stall watch / Capacity — they only ever look at focus, never all 74.
  • Leave create_arc / delete_arc gated. Everything else is safe to auto-apply since Arc Reader's Undo reverts it.
  • One webhook per destination is enough — route different event types through it rather than multiplying connectors.
Hidden connections
  • Every op here writes to the same overlay Arc Reader reads — Reader's Undo clears agent-made edits too, not just Reader's own.
  • Focus arcs are arc-momentum-focus-v1 — shared live with Arc Momentum.
  • Custom agents and the goal planner both run on the same three-provider adapters and stored keys as Arc Reader's assistant — a key you add there works here.
  • Approved/rejected ops and connector sends land in the same activity log — scroll it as a single source of truth for what the agent actually did.
Pro moves
  • Chain it in one goal: "run stall watch, then post the result to Slack" — the planner sequences skill → connector without you doing it by hand.
  • Wiring a new MCP server, test it first — the Test button initializes a session so you can confirm the tool name before pointing real goals at it.
  • Give a custom agent's description a full standing instruction and no blanks to fill — its Run button becomes a real one-click job.
  • Name arcs and connectors precisely in your goal text ("the mcp arc", "the n8n webhook") — the planner matches on exact ids/names, not fuzzy guesses.
Unknown unknowns
  • A connector failure with no HTTP status (just a network error) usually means the browser blocked the request via CORS — not a bad token. Notion, Linear and Gmail commonly do this from client-side code.
  • The planner only sees connectors/agents/arcs that exist the moment you hit Run — add a connector, then re-run the goal so it's in scope.
  • Anthropic's free-tier replies cap around 1024 tokens (same limit as Reader's assistant) — a long create_arc draft or a verbose custom-agent prompt can get cut off; switch providers for those.
  • Overlay sync is load-time only, suite-wide — an edit made here won't show in an already-open Portfolio/Dependencies tab until it's reloaded.
