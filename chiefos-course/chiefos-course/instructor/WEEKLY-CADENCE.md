# Weekly Cadence

Repeatable rhythm. ~4–6 student hours/week.

| When | Who | What |
|---|---|---|
| Before class | Student | Read `LESSON.md` |
| Live session (90 min) | Instructor + cohort | Recap → demo → guided reps → assign |
| After class | Student | `EXERCISES.md` reps |
| End of week | Student | `CHECK.md` self-check + submit |
| Rolling | Instructor/TA | Grade reps against `weekly-rubric.md` |

## Time budget per week (student)
- Reading lesson: 20–30 min
- Live session: 90 min
- Reps: 90–150 min
- Submit: 15 min

## Gate weeks (4, 8, 12) run heavier
Add a resubmit window. Nobody advances a phase on a "not yet." Build a 2–3 day buffer after
each gate for resubmissions before the next phase starts.
