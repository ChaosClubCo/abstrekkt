# FSR Pipeline: Course → ChiefOS Field Service Rep

This course is ChiefOS's talent pipeline. Each phase proves an FSR-relevant competency.

## Skill mapping
| Course skill | FSR job reality |
|---|---|
| Operate a terminal on any machine (Ph 1) | Day-one at an unfamiliar customer site |
| Git + version control (Ph 1) | Track and recover changes to deployed configs |
| Read code you didn't write (Ph 2) | Understand a system without its author present |
| Run Docker containers (Ph 2) | Deploy/run ChiefOS in a container at a site |
| Debug with method (Ph 2) | Fix it on-site instead of escalating |
| Supervise agentic workflows (Ph 3) | Monitor ChiefOS's agents safely in the field |
| Build + deploy + defend an app (Ph 3) | Ship and stand behind working software |

## Selecting the shortlist
The capstone defense IS a proxy FSR interview: ship something, then answer "why this?" and
"what breaks if X?" under questioning. Prioritize for interviews:
1. Passed all gates on merit (not just resubmit-until-passed).
2. Capstone Ownership score ≥ 25/30 — they can explain their system cold.
3. Strong defense Q&A — thinks on their feet about failure modes.
4. Helped peers (teaching = FSR communication skill).

## What to tell students (motivation, honestly framed)
Strong performers get an FSR interview. The bar isn't "wrote the most code" — it's "can ship
and defend working software." That's what the capstone measures and what the job requires. No
guarantees are promised beyond an interview shot; the work speaks.
