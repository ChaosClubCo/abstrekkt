# Week 8 — Check & Submit (PHASE 2 GATE)

## Gate criteria (all required to pass Phase 2)
- [ ] All 3 bugs found and fixed; program runs clean.
- [ ] `debug-log.md` shows a hypothesis BEFORE each fix (not just the fix).
- [ ] Each fix addresses the cause, not the symptom.
- [ ] The fixed program runs inside a Docker container you built.

## Submit
1. Fixed `buggy.js` (in a repo, committed).
2. `debug-log.md` with hypothesis → test → fix for all 3.
3. Output of `docker run` on your containerized version.
4. One paragraph: describe the debugging loop in your own words.

## Instructor grading note (gate)
- Pass: hypotheses are real (even if some were wrong before landing the fix); container runs.
- The point is the METHOD. A student who fixed bugs by random editing but wrote no hypotheses fails the gate — send them back to log their reasoning.
- Not yet: "I asked AI to fix it" with no understanding. Have them explain bug 2's off-by-one out loud.

**Phase 2 complete. FSR skill proved:** You can diagnose a broken system in the field with a
repeatable method — the difference between an FSR who fixes it and one who calls for help.
