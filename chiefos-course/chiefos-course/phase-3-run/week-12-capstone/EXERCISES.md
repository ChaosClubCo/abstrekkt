# Week 12 — Exercises (FINAL CAPSTONE)

## Step 1 — Proposal (get it approved early in the week)
`capstone-spec.md`:
- What it does, who it's for (2–3 sentences).
- Feature list (keep it finishable — 3 to 5 features).
- Where AI/an agent fits, and where a human stays in the loop.
- Acceptance criteria: "done means..."
Get instructor sign-off before building. Overscoping is the #1 capstone failure.

## Step 2 — Build (use the whole course)
- Spec → architecture → slice-by-slice build (Week 10 method).
- AI-paired, human-reviewed (Week 7).
- Debugged with method (Week 8).
- Committed continuously with real messages (Week 3).
- Secrets externalized from the start (Week 11).

## Step 3 — Deploy
Live public URL. Smoke-tested from a device that isn't your dev machine. No secrets in the repo.

## Step 4 — Write the defense doc
`DEFENSE.md`:
- Architecture: the pieces and how they talk (one diagram).
- "Explain every file" — 1–3 sentences each.
- Where AI helped and how you verified it.
- One bug you hit and how you diagnosed it (the loop).
- One thing you'd improve with more time.

## Step 5 — Prepare the 5-minute demo
Rehearse the structure from LESSON.md. Have the live URL and the code open. Be ready to open
any file and explain it on the spot.
