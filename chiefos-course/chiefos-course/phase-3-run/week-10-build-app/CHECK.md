## Instructor grading note
- Full: app works, persists, and the student can explain every file. The commit history shows slice-by-slice building, not one giant "add app" commit.
- Big red flag: a single commit dumping the whole app = they let AI build it all and can't explain it. Check `walkthrough.md` hard; ask them to trace the delete feature live.
