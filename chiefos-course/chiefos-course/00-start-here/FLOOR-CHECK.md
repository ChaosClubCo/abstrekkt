# Floor Check (ungraded, private)

Ten minutes. Nobody sees this but you. Its only job is to tell you where you're starting
so you notice how far you climb by Week 12.

For each, circle honestly: **Can't yet · With help · On my own**

1. Open a terminal and navigate to my Desktop folder using only commands. `Can't · Help · Own`
2. Explain what a "file path" is. `Can't · Help · Own`
3. Say what `git commit` does. `Can't · Help · Own`
4. Say what a Docker container is. `Can't · Help · Own`
5. Read a 20-line function someone else wrote and say what it does. `Can't · Help · Own`
6. Read an error message and guess where the problem is. `Can't · Help · Own`
7. Write a prompt that gets an AI to produce working code. `Can't · Help · Own`
8. Look at AI-generated code and spot something wrong with it. `Can't · Help · Own`
9. Deploy an app so someone else can open it in a browser. `Can't · Help · Own`
10. Explain the difference between "using AI to code" and "coding." `Can't · Help · Own`

---

**Scoring:** There is none. Mostly "Can't yet"? Perfect — that's the median student here
(the survey agrees). The goal by Week 12 is mostly "On my own." Keep this page. Retake it
at the end.
