## Who this is for

This course was designed **from your own survey data** (41 respondents). It assumes:

- You are **not confident writing code** (51% of you rated yourselves "not confident at all").
- You have **never shipped an app** (66% "not yet"; only 7% have shipped something real).
- You have **little/no Git** (41% "none," another 41% "awareness only").
- You have **little/no Docker** (56% beginner/none).
- You **want** to learn AI-assisted coding and agentic workflows (top stated goal).

So we start at the floor — **CLI typing drills** — and climb to **agentic app delivery**.
Nobody gets left at the "prompt-and-pray" stage.

## The three phases

| Phase | Weeks | Theme | You leave able to... |
|-------|-------|-------|----------------------|
| 🐣 **Crawl** | 1–4 | Muscle memory | Move around a terminal, use Git, make your first repo without fear |
| 🚶 **Walk** | 5–8 | Comprehension | Read code you didn't write, run Docker, pair with AI, debug on purpose |
| 🏃 **Run** | 9–12 | Delivery | Drive an agentic workflow, build + deploy a real app, ship a capstone |

## How to use this repo

1. Read [`00-start-here/README.md`](00-start-here/README.md) **first**. It sets up your machine.
2. Each week lives in its own folder: `phase-X/week-NN-topic/`.
   - `LESSON.md` — what you learn and why (read this).
   - `EXERCISES.md` — what you do (do this).
   - `CHECK.md` — how you know you're done (self-check + what to submit).
3. Do the weeks **in order**. Crawl before you walk. This is not optional — the survey
   says the cohort skips fundamentals and stalls at "vibe coding." We're fixing that.

## Grading philosophy

**You are graded on process, not perfection.**
- Did you attempt the reps?
- Can you explain what your code / your AI did?
- Did you iterate when it broke?

A working app you can't explain scores **lower** than a broken app you understand.
See [`rubrics/`](rubrics/) for exact criteria.
