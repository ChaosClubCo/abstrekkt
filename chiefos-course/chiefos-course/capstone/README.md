# Capstone

Your final project. Ship a real app and defend it. See the Week 12 folder for the full
workflow and the rubric in `rubrics/capstone-rubric.md`.

Files here:
- `IDEA-BANK.md` — finishable project ideas if you're stuck.
- `capstone-spec-template.md` — copy this to start your proposal.
- `DEFENSE-template.md` — copy this to prepare your defense.

## The bar, one more time
Small + working + deployed + understood + defended **beats** ambitious + broken + unexplained.
Choose something you can finish and explain. That's the FSR bar.
