# Capstone Idea Bank

Pick something finishable in a week that you'd actually use or show. Each should have 3–5
features and ideally one AI/agentic step you supervise.

## Solid, finishable ideas
1. **Personal task/habit tracker** — add, list, complete, delete; persists; optional AI that
   suggests a priority order (you review the suggestion — HITL).
2. **Link saver** — save URLs with tags, list/filter, delete; optional AI auto-tagging you approve.
3. **Study flashcards** — create decks, review, mark known; optional AI that generates cards
   from pasted notes (you edit before saving — HITL).
4. **Expense logger** — add expenses, categorize, monthly total; AI categorizes, you confirm.
5. **Simple support-ticket triage** — submit an issue, AI drafts a category + priority, a
   human approves before it's "filed." (Mirrors the Week 9 agent diagram — great FSR story.)
6. **Recipe box** — add/search recipes; AI suggests a recipe from ingredients you have (you pick).

## What makes any of these strong
- One place where an AI does real multi-step work AND a human stays in the loop.
- Data that persists (survives restart).
- Something you can demo live and explain every file of.

## Avoid
- Clones of huge apps (you won't finish).
- Anything with no persistence (feels fake in the demo).
- Anything you can't explain — impressive-but-opaque fails Ownership.
