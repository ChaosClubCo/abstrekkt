# Rubrics

Grading is **process over perfection**. A student who understands a broken thing scores
higher than one who ships a working thing they can't explain. That single principle defends
the whole course against the "prompt-and-pray" failure mode the survey revealed.

- `weekly-rubric.md` — how any week's reps are graded (40% of course).
- `phase-gate-rubric.md` — the three gates (Weeks 4, 8, 12-precursor) — 30% total.
- `capstone-rubric.md` — the final project (30%).

## Course grade breakdown
| Component | Weight |
|---|---|
| Weekly reps | 40% |
| Phase gates (Wk 4, Wk 8) — 10% each | 20% |
| Capstone (Wk 12, includes final gate) | 30% |
| Participation / helping peers | 10% |
