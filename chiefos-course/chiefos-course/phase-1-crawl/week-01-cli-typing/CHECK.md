# Week 1 — Check & Submit

## Self-check (you're done when all are true)
- [ ] I can say what `pwd`, `ls`, `cd`, `mkdir`, `touch`, `cat` do without looking.
- [ ] I use **Tab** to autocomplete and **Up arrow** to reuse commands.
- [ ] I beat the 15-second challenge (Drill 3).
- [ ] I wrote text into a file and read it back with `cat`.

## Submit (process-graded)
Run this and paste the full output into the class channel:

```bash
cd ~/week1-practice
pwd
ls -la
history | tail -20
```

That last line proves you did the reps. We grade **effort and understanding**, not polish.

## Instructor's grading note
- Full credit: output shows real practice (folders made, files created, 20 lines of history).
- Half credit: partial reps, but student can explain what each command does.
- Redo: pasted commands with no evidence of repetition — that's the "prompt-and-pray" habit
  we're breaking. Ask them to explain `cd ..` out loud.

**FSR skill proved:** You can operate an unfamiliar machine from a terminal — the #1 thing a
Field Service Rep does on day one at a site.
