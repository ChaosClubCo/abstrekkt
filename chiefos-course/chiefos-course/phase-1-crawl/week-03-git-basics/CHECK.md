# Week 3 — Check & Submit

## Self-check
- [ ] I can explain the three zones (working / staging / repository).
- [ ] I made 5+ commits with real messages.
- [ ] I created a branch, committed on it, and merged it.
- [ ] My repo is pushed and visible on GitHub.

## Submit
1. The **URL** of your `git-practice` repo on GitHub.
2. The output of:
```bash
cd ~/git-practice
git log --oneline
```

## Instructor grading note
- Full: repo is live on GitHub, 5+ meaningful commit messages, a merged branch in history.
- Half: local commits fine, push failed — pair them for the remote step, it's a common snag.
- Redo: commit messages are all "update"/"asdf" — that means they didn't internalize *why* we commit. Have them narrate their history.

**FSR skill proved:** You can version and back up work, and recover from mistakes — table stakes for anyone touching a deployed system.
