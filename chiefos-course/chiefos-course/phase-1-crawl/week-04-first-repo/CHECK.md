# Week 4 — Check & Submit (PHASE 1 GATE)

## Gate criteria (all required to pass Phase 1)
- [ ] `my-profile` repo is live on GitHub.
- [ ] 5+ commits with meaningful messages across the repo.
- [ ] At least one branch was opened and merged **via a pull request** (not a direct push).
- [ ] The page renders in a browser.

## Submit
1. Repo URL.
2. The merged **PR URL**.
3. One paragraph: describe the full loop (`branch → edit → commit → push → PR → merge`) in
   your own words. This paragraph is worth as much as the code.

## Instructor grading note (gate)
- Pass: PR exists and is merged; student can narrate the loop.
- Not yet: pushed straight to main with no PR — the PR *is* the lesson. Send back to Step 5.
- The written paragraph filters "did it" from "understood it." Weight it heavily.

**Phase 1 complete. FSR skill proved:** You can take an unfamiliar machine, produce a tracked
change, and route it through review — the daily rhythm of every field deployment.
