🚀 Quick Installation & Usage
Step 1: Save and Run the Master Installer
bash# Make the installer executable
chmod +x master-installer.sh

# Run the complete installation
./master-installer.sh install
Step 2: Use the Agent System
bash# Check system status
agent-cli status

# Start all agents
agent-cli start

# Deploy with Docker
agent-cli deploy docker

# View agent logs
agent-cli logs tessa

# Security audit
agent-cli security audit
