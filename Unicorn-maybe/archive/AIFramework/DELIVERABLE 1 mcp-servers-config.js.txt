## 🛠️ Troubleshooting

### Common Issues

#### Error: `ENOENT: no such file or directory`

**Cause:** Missing config file  
**Fix:** Ensure `mcp-servers-config.json` is in correct path  
**Retry:** Yes, after copying file
```bash
# Verify path
ls -la ~/.config/mcp/mcp-servers-config.json

# Or copy to home directory
cp mcp-servers-config.json ~/
```

#### Error: `401 Unauthorized`

**Cause:** Missing or invalid API token  
**Fix:** Verify token in .env file  
**Retry:** Yes, after adding correct token
```bash
# Check env var is loaded
echo $GITHUB_PERSONAL_ACCESS_TOKEN

# Test token directly
curl -H "Authorization: Bearer $GITHUB_PERSONAL_ACCESS_TOKEN" \
  https://api.github.com/user
```

#### Error: `Rate limit exceeded`

**Cause:** Too many API calls  
**Fix:** Wait for rate limit reset or upgrade plan  
**Retry:** Yes, after cooldown (typically 1 hour)
```bash
# Check rate limit status (GitHub example)
curl -H "Authorization: Bearer $GITHUB_PERSONAL_ACCESS_TOKEN" \
  https://api.github.com/rate_limit
```

### Debug Mode
```bash
# Enable verbose logging
export DEBUG=mcp:*

# Test server with debug output
npx -y @modelcontextprotocol/server-github
```

## 🐛 Known Issues

### Issue 1: npx Caching

**Symptom:** Old server version loaded  
**Workaround:** Clear npx cache
```bash
rm -rf ~/.npm/_npx
npx -y @modelcontextprotocol/server-github
```

### Issue 2: Environment Variables Not Loading

**Symptom:** Undefined env vars in server  
**Workaround:** Explicitly export before running
```bash
export $(cat .env | xargs)
npx -y @modelcontextprotocol/server-notion
```

### Issue 3: EACCES Permission Denied

**Symptom:** Cannot write to global npm  
**Workaround:** Fix npm permissions
```bash
mkdir -p ~/.npm-global
npm config set prefix '~/.npm-global'
export PATH=~/.npm-global/bin:$PATH
```

## 🔒 Phase 5: Security Hardening

### 1. Token Rotation Schedule
```bash
# Create rotation reminder script
cat > ~/.config/mcp/rotation-check.sh << 'EOF'
#!/bin/bash
echo "Last rotation: 2025-12-21"
echo "Next rotation due: 2026-03-21 (90 days)"
echo "Days remaining: $(($(date -d "2026-03-21" +%s) - $(date +%s)) / 86400))"
EOF

chmod +x ~/.config/mcp/rotation-check.sh

# Add to crontab (weekly reminder)
(crontab -l 2>/dev/null; echo "0 9 * * 1 ~/.config/mcp/rotation-check.sh") | crontab -
```

### 2. Audit Logging
```bash
# Create audit log directory
mkdir -p ~/.mcp-logs
chmod 700 ~/.mcp-logs

# Log wrapper script
cat > ~/.config/mcp/audit-wrapper.sh << 'EOF'
#!/bin/bash
TIMESTAMP=$(date -u +"%Y-%m-%dT%H:%M:%SZ")
SERVER=$1
shift

echo "{\"timestamp\":\"$TIMESTAMP\",\"server\":\"$SERVER\",\"args\":\"$@\"}" >> ~/.mcp-logs/audit.log
npx -y @modelcontextprotocol/server-$SERVER "$@"
EOF

chmod +x ~/.config/mcp/audit-wrapper.sh
```

### 3. Least Privilege Review
```bash
# GitHub: Review token scopes
# Go to: https://github.com/settings/tokens
# Verify minimum required scopes
# Remove admin:org if not needed

# AWS: Review IAM permissions
aws iam get-user-policy --user-name mcp-integration --policy-name ReadOnlyAccess

# Stripe: Use Restricted keys

# Grant only: Charges (read), Products (read)
```

## 🐛 Troubleshooting

### Common Setup Issues

#### Issue: npx command not found
```bash
# Fix: Install Node.js
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs
```

#### Issue: Permission denied writing to .env
```bash
# Fix: Check file permissions
ls -la ~/.config/mcp/.env
chmod 600 ~/.config/mcp/.env
```

#### Issue: Environment variables not loading
```bash
# Debug: Print variables
source ~/.config/mcp/.env
env | grep -E "(GITHUB|NOTION|STRIPE)"

# Fix: Ensure no quotes around values in .env
# WRONG: GITHUB_PERSONAL_ACCESS_TOKEN="ghp_xxxx"
# RIGHT: GITHUB_PERSONAL_ACCESS_TOKEN=ghp_xxxx
```

#### Issue: 401 Unauthorized from API
```bash
# Verify token is valid
# GitHub example:
curl -H "Authorization: Bearer $GITHUB_PERSONAL_ACCESS_TOKEN" \
  https://api.github.com/user

# If invalid: Regenerate token
# Go to provider dashboard → Generate new token
```
