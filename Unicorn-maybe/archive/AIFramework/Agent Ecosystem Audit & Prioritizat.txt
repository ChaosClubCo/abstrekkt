8. Token Optimization & Circuit Breaker (P2, 16h, prevents runaway costs)
Why here: Context manager tracks tokens; no hard limits. Could silently exceed budget.
What: Hard stop at token threshold; graceful degradation (summarize old messages, drop non-critical context).
Analogy: You have a speedometer but no governor. The car can go 200 mph, but it shouldn't.
Steps:

Define thresholds:

Soft limit (75%): Log warning, start summarizing old messages
Hard limit (95%): Reject new messages, return "context full, start new session"


Implement summarization: Use Claude to condense old messages (keep last 10, summarize previous)
Add circuit breaker:

python   if context.usage_percentage() > 0.95:
       raise ContextWindowFullError("Start new conversation")

Test: Feed 100K tokens, verify behavior at 75% and 95%
Monitor: Log all circuit-breaker events to Sentry (learn patterns)

Owner: Backend
Blocker: None
Outcome: Cost predictability; system never OOMs
