## Architecture

### Fit Score Algorithm

The tier fit score (0-1) determines how well a tier matches usage:

```
Optimal Zone: 0.5-0.8 utilization = 1.0 fit score
Close to limits: >0.9 utilization = 0.6 fit score
Slightly under: 0.3-0.5 utilization = 0.8 fit score
Very under: <0.3 utilization = 0.5 - (0.3 - util)
Over limit: 0.3 - (over_count * 0.1)
```

### Scheduled Jobs

```sql
-- Daily usage snapshots (2 AM)
SELECT cron.schedule(
  'daily-tier-snapshots',
  '0 2 * * *',
  $$
  SELECT take_tier_usage_snapshot(tenant_id) 
  FROM subscriptions 
  WHERE status = 'active'
  $$
);

-- Daily rule evaluation (3 AM)
SELECT cron.schedule(
  'daily-rule-evaluation',
  '0 3 * * *',
  $$
  SELECT evaluate_optimization_rules(tenant_id) 
  FROM subscriptions 
  WHERE status = 'active'
  $$
);

-- Expire old recommendations (midnight)
SELECT cron.schedule(
  'expire-recommendations',
  '0 0 * * *',
  $$
  UPDATE tier_recommendations 
  SET status = 'expired' 
  WHERE status = 'pending' 
  AND valid_until < NOW()
  $$
);
```

### Edge Function (n8n Integration)

```typescript
// Webhook for tier change events
Deno.serve(async (req) => {
  const { tenant_id, from_tier, to_tier, transition_type } = await req.json();
  
  // Notify external systems
  await fetch(process.env.N8N_WEBHOOK_URL, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      event: 'tier_transition',
      tenant_id,
      from_tier,
      to_tier,
      transition_type,
      timestamp: new Date().toISOString()
    })
  });
  
  return new Response(JSON.stringify({ success: true }));
});
```

## Known Limitations

1. **Fit Score Algorithm:** Simple utilization-based; could benefit from ML
2. **A/B Statistics:** Basic conversion tracking; no p-value calculation
3. **Rule Engine:** Simple condition matching; no complex logic chains
4. **Template Variables:** String interpolation only; no conditionals
5. **Experiment Targeting:** Basic rules; no segment-based targeting
