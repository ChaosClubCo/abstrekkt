How to download your CSV (provider-specific instructions)

Anthropic:

  1. Log in to console.anthropic.com
  2. Navigate to Settings → Usage
  3. Select your date range (last 30 days recommended)
  4. Click Export or use the Admin API /v1/organizations/usage_report/messages

OpenAI:

  1. Log in to platform.openai.com
  2. Go to Usage → Activity
  3. Click Export (top right)
  4. Download as CSV

Both providers export only metadata (timestamps, models, token counts) — never prompt content. That's by design. Prompt-level analysis requires the SDK or proxy integration.

Don't have CSV access? Use Claude to extract it

Paste this prompt into Claude.ai along with a screenshot, PDF, or pasted text of your billing/usage report. Claude will return clean CSV.

I'm attaching my AI API usage data (could be Anthropic, OpenAI, or another provider). Extract every line item and output ONLY a CSV with these exact columns and no other text:

timestamp,model,input_tokens,output_tokens,cost_usd

Rules:
- ISO 8601 timestamps (YYYY-MM-DDTHH:MM:SSZ); if only date is available, use T00:00:00Z
- One row per request, or one row per aggregated daily line if request-level isn't shown
- Round costs to 6 decimal places; use 0 if cost isn't shown
- Use the model name as it appears (e.g. "claude-sonnet-4-5", "gpt-4-turbo")
- No code fences, no preamble, no explanation, no trailing commentary
- First line must be the header row; remaining lines are data

Once Claude returns the CSV, save it to a .csv file and upload above.

What's next: continuous monitoring

This tool gives you a one-shot audit. The full FlashFusion AI Cost Optimizer dashboard adds continuous tracking, real prompt-similarity detection (not just token-count clustering), and auto-applied optimizations via SDK or proxy. Below is the architecture currently in build.

01 · Ingestion

SDK middleware (Node, Python) and HTTP proxy. Live cost stream, not nightly batch.

02 · Storage

Supabase Postgres with RLS. Per-org isolation. Prompts hashed, never stored raw.

03 · Analysis

MinHash + LSH for true semantic clustering. Token estimation per-model with calibrated ratios.

04 · Auto-fix

Routing rules pushed to your SDK as config. No code regen. Versioned, rollback-able.

05 · Alerts

Slack / email on spend anomalies, budget breach, model-config drift.

06 · Reports

Weekly digest. ROI-tracked savings, before/after comparison, trend forecasting.
