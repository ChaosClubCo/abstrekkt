The 30-second test

Does this carry real load — or is the building itself the calm?

Load-bearing

Carries weight the system needs. Without it, substrate, infrastructure, or income visibly degrades.

Signs

  • Names a specific user, customer, or lane it serves
  • Failure mode is concrete — X breaks if this doesn't ship
  • The work to add it is annoying, not relieving

Activation

The building is what makes the substrate calm enough to function. Legitimate. Just not load-bearing.

Signs

  • "I'll figure out where it fits later"
  • Spec'd to higher precision than current need requires
  • Drafting the architecture feels better than the deploy

The verdict

Load-bearing → build it. No guilt.

Activation → fine. But name it. Don't ship it as infrastructure.

Can't tell → it's activation. Treat it that way until the load shows up.
