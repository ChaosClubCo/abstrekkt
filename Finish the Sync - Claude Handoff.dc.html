Arc System // Persistence handoff

Let Claude finish the sync.

Every tool here runs fine on localStorage alone — this is optional. It's a durable Supabase copy of the overlay, so edits survive a wiped browser, plus the groundwork for an MCP server that can act on your arcs without a tab open. Four things need your choices below.

✓ Live now — no setup
  • Every op fire-and-forget pushes through arc-sync.js, arc-github.js and arc-obsidian.js (each no-ops until configured)
  • All seven tools poll and fold in remote changes once Supabase is configured
  • Additive only — none of the three can corrupt the local overlay
◷ Needs your setup
  • Supabase: project + schema + URL/key in step 04 (Edge Function optional)
  • GitHub: a repo + fine-grained token in step 05 (optional)
  • Obsidian: the Local REST API plugin running + its key in step 06 (optional)
01

Create the project

At supabase.com/dashboard — new project, any region, free tier is plenty for one user's overlay log. Copy the Project URL and the anon public key from Settings → API for step 04.
