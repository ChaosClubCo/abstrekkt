# Knowledge Operating System

The Abstrekkt Knowledge Operating System is the governance layer for knowledge distributed across GitHub, GitBook, Worldkeep, Orbismo, and the Base44 Hub.

Its central rule is simple: **a fact has one canonical owner**. Other systems may reference, project, index, or orchestrate that fact, but they should not silently maintain competing writable copies.

## Core layers

- **GitHub** — durable, versioned source artifacts and change history.
- **GitBook** — canonical human-readable operational documentation.
- **Worldkeep** — structured ecosystem canon and semantic relationships.
- **Orbismo** — operational relationship graph and lightweight lifecycle metadata.
- **Base44 Hub** — unified control and orchestration plane over the canonical systems.

The architecture prefers explicit ownership and derived projections over unrestricted bidirectional synchronization.
