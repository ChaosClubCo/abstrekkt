# Loxihart

Loxihart is the operating company within the Abstrekkt structure, focused on AI enablement, client services, software systems, and governed AI implementation.

## Approach

Loxihart emphasizes production trust: requirements are tied to implementation, deterministic verification, runtime proof, preserved evidence, and explicit release decisions.

Detailed internal architecture, repository mappings, authority contracts, security controls, and operational evidence remain in the private documentation plane.
