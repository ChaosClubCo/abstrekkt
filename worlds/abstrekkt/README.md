# Abstrekkt Ecosystem Worldkeep Canon

This directory is the structured Worldkeep canon for the Abstrekkt ecosystem.

- `world.yaml` defines the world manifest.
- `types/` contains reusable vocabulary.
- `entities/` contains modeled systems and platforms.
- `relations/` contains explicit connections.
- Initial ecosystem records are intentionally `status: draft`.

Git history is the durable record. Do not store credentials or secrets in canon files.
