Hard rules vs. FlashFusion: No gradients on strokes. No drop-shadow bloom. No blur. Border-radius 8px (not 12px). Font stack Inter + JetBrains Mono (not Instrument Serif + Geist). Backgrounds #0f0f0f/#1a1a1a (not #0B0B14/#13131F). Icons map to brand pillars — human, community, growth, cycles, progress — not product categories.
Context of use
Tier 1 · Glyph box
Pillar cards · feature sections
44×44 · 8px radius · flat tinted bg · stroke="currentColor" · r/o/a variants for red/orange/amber. Matches pillar grid layout in CC landing.
Tier 2 · Flat accent
Pillar lists · inline markers
No box. Single-color stroke from palette. Rotates r→o→a across sets of 3. Used in blog posts, course cards, community feature callouts.
No Tier 3
No neon. No glow. Full stop.
CC brand is warm, grounded, human. Neon glow is a FlashFusion signal. If it glows, it's the wrong brand. The only exception: a single red glow on the CC wordmark itself, never on content icons.
