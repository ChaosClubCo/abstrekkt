## 3. Code fix applied this session

### `Abstrekkt Pillars.html` — mobile nav script tag (upstream fix)

**Problem:** `Abstrekkt Pillars.html` had the full `.nav-toggle` CSS, the `<button class="nav-toggle">` markup, and the `aria-expanded` wiring — but was missing `<script src="abstrekkt/nav-toggle.js"></script>`. The mobile hamburger button was present and styled but non-functional.

**Fix:** Added `<script src="abstrekkt/nav-toggle.js"></script>` immediately before `</body>`, matching the pattern used by all other studio pages (`Abstrekkt Home.html`, `Abstrekkt Contact.html`, `Abstrekkt Founder.html`).

**Note from CANON.md (Aug 11, 2026):** the deploy copy at `deploy/abstrekkt-com/pillars/index.html` already carried this script tag when the deploy package was generated. This fix brings the canonical source into parity with its own deploy output.
