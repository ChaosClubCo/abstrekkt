The Gap Between the Sales Page and the Setup

An AI feature list, a skill catalog, and a "digital employee" sales page walked into a bar. Here's what they ordered, and what they actually got served.

Three images crossed my feed this month. A ChatGPT feature matrix listing 17 capabilities. A catalog of 31 pre-built Claude skills for small businesses. And a product called Sierra 2.0 that promises to be your "fully-automated AI employee", 24/7 available, no breaks, no fatigue, 100% consistent.

They represent three points on the same spectrum: how AI tools present themselves versus what actually happens when you try to use them.

Maximum hype

Sierra 2.0

"Your fully-automated AI employee." 9 core capabilities. Lifetime usage rights. Deploy in minutes.

Reality check: It's an n8n workflow with a Telegram bot frontend. The "visual intelligence" is API calls to a vision model. The "lifetime rights" are to a JSON file. None of this is wrong, but "AI employee" is doing a lot of heavy lifting for what's actually a well-packaged automation template.

Honest but incomplete

ChatGPT Feature Matrix

17 features: Web Search, Deep Research, Vision, Voice, Canvas, Agent Mode, etc.

Reality check: Features exist as described. What's missing: which plan you need for each, rate limits, what "Agent Mode" actually does vs. what it implies, and the fact that most users will use 3-4 of these features regularly and never touch the rest.

Most useful

Claude for Small Business (31 Skills)

31 named skills with specific connector requirements. Cash-flow-snapshot, invoice-chase, customer-pulse, contract-review.

Reality check: The skill names are specific and the connector requirements are visible. The gap: these assume your QuickBooks, PayPal, Stripe, HubSpot, and Google accounts are already connected and authorized. For most small businesses, the setup is the hard part, not the skill.

Why This Matters for Anyone Buying AI Services

The spectrum above isn't unique to these three products. It's the standard pattern in AI tooling right now: the capability is real, the implementation gap is hidden, and the marketing bridges both with confidence.

When Sierra 2.0 says "deploy in minutes," they mean: download the workflow JSON, import it into n8n, configure your API keys, set up the Telegram bot, authorize the Google Calendar integration, set up the Gmail connection, configure the Whisper transcription, and test each capability individually. That's not minutes. That's hours, if everything works on the first try.

When the ChatGPT feature matrix says "Agent Mode, uses agents to complete multi-step tasks autonomously," they mean: a loop that breaks complex requests into subtasks, executes them sequentially, and sometimes gets stuck. It works. It's also not what "autonomously" implies to someone who hasn't used it.

The pattern
Every AI product pitch contains three layers: (1) the capability, which is usually real; (2) the setup, which is always harder than implied; and (3) the ongoing maintenance, which is never mentioned. An AI Setup Audit exists specifically to evaluate all three layers before you commit budget.

The Six Questions Nobody Asks Before Buying

Whether you're evaluating a pre-built skill catalog, an automation template, or a full "AI employee" product, these are the questions that separate a useful tool from a shelf decoration:

1.
What connections does it actually need? The 31-skill catalog is honest about this, each skill lists its connector icons. Most AI product pages bury this in docs or don't mention it at all. If a tool needs five integrations and you have two of them, you're buying setup time, not a solution.
2.
What happens when an API changes? The Sierra 2.0 workflow depends on specific API endpoints for Google Calendar, Gmail, and web scraping. APIs change. Endpoints deprecate. Who maintains the workflow when it breaks in three months? If the answer is "you," that's not a product, it's a project.
3.
What does "works" look like for your data? A cash-flow-snapshot skill that reads QuickBooks data is useful if your QuickBooks data is clean. If your chart of accounts is a mess, the skill will faithfully summarize your mess. AI doesn't fix data quality. It amplifies whatever quality already exists.
4.
What's the per-run cost? Every AI API call costs money. A daily summary that makes 10 API calls at $0.02 each is $6/month. A real-time monitor that runs every 5 minutes is $175/month. The sales page says "unlimited." The API bill says otherwise.
5.
What does it do with your data? That "AI employee" needs read access to your email, calendar, and documents. Where does that data go? Is it logged? Is it stored? Is it used for training? The Sierra 2.0 page promises "100% consistent" but says nothing about data handling.
6.
What's the fallback when it fails? AI tools fail silently. A skill that can't reach QuickBooks doesn't throw an error, it just returns incomplete data. A calendar automation that misreads a timezone doesn't crash, it books you for 3am. What's the detection mechanism? Who notices?

Where I Land

The 31-skill catalog is the most honest of the three because it shows you the connectors, names the specific tasks, and implies a realistic scope (one skill = one job). The ChatGPT feature matrix is fine as a reference card but teaches you nothing about when to use what. The "AI employee" pitch is the kind of thing that sells well and supports poorly.

The common thread: none of them tell you what happens after the screenshot. After the install. After the first week. After the API key expires and nobody notices for a month.

That's not a flaw in these specific products. It's a gap in the market. The gap between "here's what AI can do" and "here's what AI does for your specific setup, with your specific data, maintained by your specific team." Filling that gap is an audit, not a feature list.
