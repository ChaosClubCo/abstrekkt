Detailed Specs
01
Morning Briefing
n8n Build queue
Trigger
Cron → Daily 6:00 AM CT
What it does
Pulls calendar, starred email, weather (Gages Lake/Mundelein), and Notion top 3 tasks. Formats as scannable email. Sends to kylerosebrook@gmail.com. Posts compact version to personal Slack.
Integrations
  • Google Calendar API — today's schedule
  • Gmail API — unread count + IMPORTANT/STARRED
  • Weather API — Gages Lake high/low/precip
  • Notion API — top 3 tasks by priority
  • Gmail — delivery to personal inbox
  • Slack — compact copy to personal workspace
Acceptance criteria
  • Arrives by 6:05 AM CT every day without exception
  • Fully scannable in under 30 seconds
  • Weather is Gages Lake specific, not Chicagoland generic
  • If any source fails, briefing still sends with [Service unavailable] placeholder + Slack error alert
02
Content Research Aggregator
n8n Build queue
Trigger
Cron → Every 6 hours (4× daily)
What it does
Pulls 9 RSS feeds, deduplicates by URL, filters last 24h, scores by keyword relevance (MCP, agents, Claude, enterprise AI, security, Supabase, Vercel). Sends scored items to Claude Sonnet for 2-3 sentence summary + signal strength 1-5 + tier assignment. Writes to Notion Research Inbox.
RSS Sources
  • Anthropic Blog
  • OpenAI Blog
  • Google AI Blog
  • The Verge (AI section)
  • TechCrunch (AI section)
  • Hacker News (top 30, AI/ML/MCP filter)
  • arXiv (cs.AI + cs.CL, last 24h)
  • Ars Technica
  • Simon Willison's blog
Notion Research Inbox schema
Title · Source · URL · Summary (Claude, max 3 sentences) · Signal Strength (1-5) · Audience Tier (T1/T2/T3) · Status (Unreviewed → Selected → Used → Archived) · Tags
Acceptance criteria
  • 10-30 scored articles in Notion daily with no manual intervention
  • Zero duplicate URLs written
  • Claude summaries under 3 sentences, emphasize practical business impact
  • RSS timeout skips failed source, continues rest; Claude rate limit = exponential backoff
03
Newsletter Production Pipeline
n8n Zapier Build queue — needs #2 first
Phase A trigger (n8n)
Manual webhook OR cron Monday 8:00 AM CT
Phase A — Draft Assembly
Fetches Notion Research Inbox items with Status = "Selected". Groups by tier, sorts by signal strength. Sends to Claude Sonnet with newsletter editor prompt. Saves draft to Notion "Newsletter Drafts" database. Alerts Kyle via Gmail + Slack.
Phase B trigger (Zapier)
Kyle changes draft Status to "Approved" in Notion
Phase B — Distribution
  • Tier 1 → HTML email via Beehiiv/Substack/Resend to main list
  • Tier 2 → Markdown to Slack/Teams channel
  • Tier 3 → Email to AI Team distribution list
  • Notion status → "Published"
Acceptance criteria
  • Full 3-tier draft in Notion in under 5 minutes
  • Distribution triggers within 2 minutes of approval
  • Claude failure = partial draft with [GENERATION FAILED — MANUAL WRITE REQUIRED] tag
04
Social Distribution
Zapier Make Build queue — needs #3 first
Trigger
Webhook from #3 Phase B on newsletter publish
Zapier cross-posting
  • LinkedIn: hook + 3 takeaways + CTA link. Posts immediately.
  • Twitter/X: hook tweet + 3-5 tweet thread. Posts immediately.
Make repurposing (to queue, not auto-publish)
  • Top insight → Claude → LinkedIn Article draft → Notion Content Queue
  • Contrarian take → Claude → Engagement tweet → Notion Content Queue
  • Core case study → short-form newsletter text → Notion Content Queue
Hard rule
Repurposed content NEVER auto-publishes. Always sits in Notion queue for manual review. This is non-negotiable.
05
Lead Capture & CRM
Zapier Build queue — independent, can build any time
Trigger
Form submission on audit.flashfusion.co (Tally/Typeform/Google Form)
Flow
Filter for valid email + company + use case. Create Notion record in "Consulting Pipeline" database. Send auto-reply via Gmail (engagement scope + 48h timeline). Post Slack alert to personal channel with name, company, use case, and link to Notion record.
Notion Consulting Pipeline schema
  • Name, Email, Company, Use Case
  • Source (Newsletter / LinkedIn / Referral / Other)
  • Status (New Lead → Contacted → Scoping → Proposal → Active → Closed)
  • Date Received, Estimated Value, Next Action
Acceptance criteria
  • CRM record created and auto-reply sent within 1 minute of submission
  • Slack notification includes clickable link to the Notion record
  • Notion failure → Google Sheet backup row + Slack emergency alert
06
Personal Life & Home
n8n Zapier Build queue — last
6a — Weekly Review (n8n)
Cron → Sunday 7:00 PM CT. Notion tasks completed + open + pipeline. Calendar for next week. Claude generates weekly review summary. Emails Kyle + creates Notion log page.
6b — Household Reminders (Zapier)
Tuesday 7PM → trash night. Saturday 9AM → groceries. 1st + 15th → bill check.
6c — Focus Mode (n8n)
Trigger: Google Calendar event with [FOCUS] in title. Sets Slack status to "Focus Mode — back at [end_time]" + DND. On end: clears status, resumes notifications, logs focus duration in Notion.
6d — End-of-Day Shutdown (n8n)
Cron → Weekdays 6:00 PM CT. Fetches incomplete Notion tasks. Sends shutdown email: incomplete tasks + tomorrow's first meeting + one prep item. Sets Slack to "Done for today."
