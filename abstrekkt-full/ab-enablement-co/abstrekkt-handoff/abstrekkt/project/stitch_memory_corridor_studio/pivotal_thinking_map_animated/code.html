Architecture · Decision priorities
Maintainability > Cleverness
A total ordering of what matters in a build — and a direct rejection of how most engineers actually prioritize.
Architecture▼
"Maintainability > Correctness > Security > Observability > Scalability > Performance > Cleverness."
This ranking encodes a hard-won philosophy: the most dangerous thing you can build is something only you understand. Putting Cleverness last is a rebuke to ego-driven engineering. Putting Maintainability first is Construction over Recovery applied to code — you're building for the next person to pick it up, including future you.
