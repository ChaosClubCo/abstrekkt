02

Code quality

MEDIUM

100% inline styles, with literal duplication

No stylesheet, no Tailwind, no styled tokens beyond a handful of CSS vars. Every visual decision lives in a JSX style={{…}} object. Hero.tsx is 343 lines — and the "ghost blur" layer re-declares the H1's font, size, line-height and letter-spacing verbatim so the two can drift apart with any edit.

// …40 lines later, the blur ghost repeats all four properties → copy #2
MEDIUM

Choreography by magic number

The entire entrance is timed by hardcoded setTimeouts scattered across files — boot at 2400ms, tagline scramble at 1100ms, divider 880ms, CTA 1650ms, scroll-hint 1900ms. No shared timeline, no constants. Re-tuning the sequence means hunting magic numbers across four components.

CREDIT

The motion craft is real

Setting the wreckage aside, the landing page is genuinely well made: a per-character scramble hook driven by requestAnimationFrame with proper cleanup, 3D character entrances on spring easing, a gradient "FUSION" wordmark, clip-path-bevelled CTAs, and a signal-trail canvas. This is the one artifact with a distinctive visual voice.

03

Accessibility & performance

CRITICAL

cursor: none everywhere

The root sets cursor:none and every button re-declares cursor:none to support the custom cursor. There is no fallback. On touch devices, for keyboard users, and for anyone relying on the OS pointer, the interface loses its cursor entirely — a usability and accessibility failure, not a style choice.

✓ RESOLVED — removed cursor:none from App + all 6 ff/* buttons; cursor-fix.css re-enables the custom cursor only on fine-pointer, motion-OK devices. Live in remediation/clean/dashboard.

HIGH

3-second forced boot, no escape, no reduced-motion

BootScreen blocks all content for ~2.4s + 0.6s fade on every load, with no skip control and no prefers-reduced-motion guard. Repeat visitors and motion-sensitive users are forced through it each time.

✓ RESOLVED — BootScreen now honours prefers-reduced-motion, has a Skip button, and plays once per session.

MEDIUM

Sub-AA contrast on the storytelling text

Tagline and metadata use rgba(232,213,255,0.4–0.52) on near-black. The dim ivory is atmospheric but fails WCAG AA for body text — exactly the copy a visitor most needs to read.

MEDIUM

GPU-heavy idle

Multiple blur(36px) layers, several will-change:transform,opacity hints left permanently on, and infinite decorative animations (bolts, particles, scroll-hint) run forever. On low-end hardware this is a constant battery/compositor cost for a static page.

04

What this file needs

  1. Rename to the truth

    "FlashFusion Landing" — or actually build the dashboard the name promises. Don't ship both intentions in one ambiguous file.

  2. Delete or finish the ghost router

    Remove routes.tsx, Root, NavBar, and OnboardingOverlay, or build the seven missing pages. Right now they're compile errors waiting to happen.

  3. Make motion optional

    Gate the boot sequence and infinite loops behind prefers-reduced-motion; add a skip/escape; cache "booted" so repeat visits go straight in.

  4. Restore the cursor

    Drop global cursor:none; if you keep the custom cursor, layer it over the real one and disable on touch/keyboard.

  5. Lift styles into tokens

    Move the repeated type/glow declarations into CSS custom properties or a small style module so the headline can't drift from its own ghost.
