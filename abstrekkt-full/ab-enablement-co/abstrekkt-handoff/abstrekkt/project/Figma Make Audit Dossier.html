02

Patterns across all three

Critical · brand

No shared design language

3 palettes, 3 type pairings, 3 stacks for one brand. Purple-neon vs. amber-slate vs. orange-cyan-pink. A user moving between them would not recognize them as the same company.

Critical · process

Documentation > product

Across files 2 & 3, ~100 markdown files / 65,000+ lines of "PHASE_N_COMPLETE" narration ship inside the repos. This is generation exhaust mistaken for deliverable. It buries the real code and signals churn, not progress.

Warning · craft

Naming doesn't match content

"Cohesive dashboard" is a landing page. "Enterprise Profile Builder" calls itself INT Inc., FF Inc., and Claude Profile Builder. Labels and artifacts have drifted apart.

Warning · a11y

Contrast & cursor risks

File 1 hides the cursor globally and uses sub-AA dim text on black. Files 2–3 have decent baselines but lean on low-contrast muted greys for secondary copy.

03

Relationship to Abstrekkt

For the record: none of the three match this project's Abstrekkt system — carbon #131315, golden-hour amber, blueprint blue, EB Garamond / Literata / JetBrains Mono. That's expected — FlashFusion is a separate brand. The concern isn't that they differ from Abstrekkt; it's that they differ from each other. Abstrekkt's discipline (one tonal ladder, one type system, depth via layering not gradient glow) is exactly the corrective these files need.

04

What to do next

  1. Pick one FlashFusion palette & type systemP1

    Choose a single direction — the orange/cyan or the purple-neon, not both — write it as design tokens, and apply it across all three. Right now the brand has no fixed point.

  2. Purge the markdown phase-logs from the reposP1

    Move "PHASE_N_COMPLETE" narration out of the deliverable (or delete it). Keep a single README + one architecture doc per project. ~65k lines of status prose is actively harmful to handoff.

  3. Rename to match content; resolve the identityP2

    "Cohesive dashboard" → "FlashFusion Landing". Settle whether the enterprise console is FlashFusion, INT Inc., or FF Inc. — one name, everywhere.

  4. De-dupe the enterprise treeP2

    Collapse /features and /src/features into one source of truth before they drift further apart.

  5. Promote the enterprise architecture as the standardP2

    File 2's feature-folder structure + UI primitives is the strongest foundation. Use it as the template; fold the landing page's motion ideas in as a themed layer, not a separate codebase.

  6. Fix the obvious a11y gapsP2

    Drop global cursor:none, raise muted-text contrast to AA, and gate the boot/motion sequences behind prefers-reduced-motion.
