# Release Workflow

    _Generated: 2026-06-21. Reconstruction confidence is bounded by accessible project memory/context and the current chat session._


1. Branch from main.
2. Add artifact/code/schema changes.
3. Run lint/typecheck/tests/validation script.
4. Review security/claims impacts.
5. Deploy preview.
6. Run smoke tests.
7. Merge and production deploy.
8. Record release note and rollback path.
