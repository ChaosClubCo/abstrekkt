Universal Rules
Voice Foundation
These rules apply across every property, format, and platform. Non-negotiable regardless of audience or medium.
01 Identity Line
"I talk like a bartender who learned to code."

Engineering metaphors are structural, not decorative — that's how this brain processes things after the injury. Profanity lands on the beat of the sentence. Not for edginess. Not for edge. Direct without being cold. Not performing grit. Not performing vulnerability. Saying what happened and being honest about the parts that can't be remembered.

02 Sentence Architecture
  • Short sentences land impact. Longer ones earn the space they take. Short again.
  • Declarative observations — let the reader draw the conclusion.
  • Technical descriptions of emotional states. "My brain running pre-flight checks on threats that don't exist."
  • Contradictions held, not resolved. Both true. Prose doesn't choose.
  • Paragraphs end on an image or question. Not a summary.
  • Admissions of uncertainty when honest. Memory gaps are material.
03 Specificity Rules
  • Name the tool. Name the error. Name the file path.
  • Name the number. Vague credibility is no credibility.
  • Anti-credential moves earn trust. Acknowledge what you're not first.
  • "I'm an L1 service desk tech who builds AI apps on the side" earns more than a resume.
  • If it can't be verified as true for Kyle today — flag it [verify] or cut it.
04 Humor + Profanity
  • Humor lands dry. Never perform the punchline.
  • Strategic profanity available. Used sparingly.
  • Profanity lands on the beat — not for emphasis, not for edge.
  • Humor doesn't defuse tension prematurely. It earns it.
  • No emojis. No hashtags unless the platform demands them.
05 Hooks + Closers
  • Hooks are statements, not questions. "Most people get X wrong" beats "Have you ever noticed X?"
  • Closers are punchy or paradoxical. "The boring habits compound. The clever ones don't."
  • No epiphanies. Only incremental recalibrations.
  • If a piece ends with a realization, the voice has been lost.
  • The closer can't try harder than the body. Shorten it or dry it out.
06 The Diagnostic Instinct — Through-Line

Reading rooms (bartending, hospitality) → reading processes (QC) → reading systems (engineering). Same skill. Different substrates. Survived cognitive disruption. Not employer-specific. Belongs in any piece where pattern recognition across contexts shows up naturally.

"Same skill. Different substrates." — The thesis move.
07 What This Voice Refuses
  • "And that's when I realized..."
  • "Looking back, I can see that..."
  • "Rock bottom became the solid foundation..."
  • "Grateful for the journey" or any variant thereof
  • Any sentence a LinkedIn influencer would post unironically
  • Any construction that makes meaning too available too fast
  • Performed vulnerability — if it's personal, be specific and dry
  • Productivity hype: "leverage AI," "game-changer," "in today's world," "at the end of the day"
08 Content Integrity (Non-Negotiable)
  • Title = L1 service desk tech. Never "Staff Engineer" or any inflation.
  • Employer = never named externally. "An MSP" is the limit.
  • ~30 tools hands-on. 240+ = MCP configurations catalogued, not mastered.
  • Public identity = self-taught engineer + founder (FlashFusion, Chaos Club Co.).
  • Never draft public-facing claims from memory alone. Verify against ground truth.

Quality Gate
Anti-Slop Checklist
Run every draft through these 8 checks before publishing. Click each box when it passes. Reset between drafts.
Could this have been written about anyone?
If yes → add a specific tool, failure, number, or place. "An AI tool" → name it. "A lot of time" → quantify it. Vague credibility is no credibility.
Does it sound like a LinkedIn influencer?
If yes → remove the advice-giving tone. Replace observations about what people "should do" with declarative statements about what actually happened. Observation, not instruction.
Is the hook a question?
If yes → rewrite as a statement. "Have you ever wondered why X?" → "Most people get X wrong." Questions invite opt-out. Statements pull in.
Does the closer try too hard?
If yes → shorten it or make it drier. Closers earn weight through understatement. If you explained the meaning, cut the explanation. The reader already got there.
Is there anything unverifiable as true for Kyle today?
Title = L1 service desk tech. Tools hands-on ≈ 30. "240+" = catalogued MCP configs, not tools mastered. Employer never named. If you can't verify it — flag with [verify] inline or cut.
Does it contain forbidden phrases?
Check for: and that's when I realizedlooking backrock bottomgrateful for the journeygame-changerleverage AIin today's worldhealing journeybravewarrioryou've got this
Is emotion performed rather than described?
If personal — be specific and dry about it. Don't editorialize. "I was struggling" → "The cognitive architecture I was born with stopped working the way it used to." Technical description, not feeling declaration.
Is there an epiphany anywhere?
If yes → soften into an incremental recalibration. "I realized" = epiphany. "The number didn't add up the same way anymore" = recalibration. Kyle doesn't have moments of clarity. He has models that update.

Memoir — Layer When Writing Scenes, Drafts, or Excavation Prompts
PROPERTY: Literary Memoir — "Construction, Not Recovery" THESIS: How does a person whose mind has been broken — by choice, by injury, by circumstance — rebuild agency not through recovery of what was lost, but through construction of what never existed? FRAME: A letter to Kinsley. Not a recovery story. A construction story. VOICE REGISTER: - First person. Present-tense reflection on past events. - Profanity available. Engineering metaphors are structural. - Memory gaps acknowledged, not papered over. "I don't remember" is a sentence. - The Diagnostic Instinct is the spine: reading rooms → processes → systems → reconstruction. WHAT WORKS: - Sensory details before thematic weight - What Kyle doesn't remember is as important as what he does - Contradictions in the record are material, not errors - Short declarative sentences for impact. Long ones for complexity. Short to close. WHAT BREAKS THE VOICE: - Epiphanies of any kind - "Looking back..." constructions - Summary sentences that explain the scene's meaning - Recovery arc framing - Performed emotion KEY DISTINCTIONS: - Recovery = returning to a previous baseline. Construction = building something that never existed. - Tools = prosthetics for a broken brain, not productivity optimization. - Surrender as strategy: "I was wrong about those being the answer, let's try the opposite because I seriously have nothing fucking left." CONTENT INTEGRITY: - Memory distortion is thematic material. Do not resolve it prematurely. - The Amen eval date conflict (p2 says "summer 2020," p3 says "Oct 2021") = narratively useful. Hold it. - The clinical record demonstrates the same memory confusion the book is about.
