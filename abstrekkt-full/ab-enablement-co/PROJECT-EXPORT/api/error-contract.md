# API Error Contract

```json
{"error":{"code":"VALIDATION_FAILED","message":"Request validation failed","requestId":"req_123","details":[]}}
```

Codes: `UNAUTHENTICATED`, `FORBIDDEN`, `NOT_FOUND`, `VALIDATION_FAILED`, `CONFLICT`, `RATE_LIMITED`, `MODEL_OUTPUT_INVALID`, `EXPORT_VALIDATION_FAILED`, `INTERNAL_ERROR`.
