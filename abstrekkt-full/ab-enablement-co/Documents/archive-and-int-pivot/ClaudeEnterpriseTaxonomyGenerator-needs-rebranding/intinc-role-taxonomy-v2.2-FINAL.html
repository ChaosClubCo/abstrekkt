      ⚙️ Intinc-Specific Customizable Variables
      Each role has editable fields for Intinc's specific setup. Customize as needed:
      1️⃣ AWS Implementation Details
      Default (from Intinc.com info):
      CloudTrail logging (1+ year retention)
      AWS Secrets Manager (KMS-encrypted)
      VPC isolation (private subnets)
      AWS Security Hub (continuous compliance)
      RDS encryption (AES-256)
      S3 with encryption (default: ON)

      Why customizable? Different roles need different AWS scopes (AppSec = Security Hub, Platform = all services, Contractor = none).
      2️⃣ Custom Integrations
      Intinc's 240+ tools integrated with Claude:
      Recommended: GitHub, Jira, Sentry, HubSpot, AWS, Slack
      Optional (per team): n8n, internal APIs, custom dashboards, Zapier
      Restricted (AppSec only): Threat intel feeds, vulnerability databases

      Each role config has a field to list custom integrations relevant to them.
      3️⃣ MCP Server Access
      Intinc's 13 active MCP servers (customizable per role):
      Example:
      Staff Engineer → all 13 MCP servers
      Senior Engineer → GitHub, Jira, Sentry, n8n
      Junior Engineer → GitHub, Jira only
      Contractor → GitHub (assigned repos only)
      Advisor → None
      4️⃣ Team/Department Name
      For multi-team Claude setups. Example:
      Platform Engineering Team
      AppSecurity Team
      Product Team
      Contractors (Project-Based)
      5️⃣ Slack Channel Integration
      Where Claude onboarding/policy updates go:
      #engineering-claude (all engineers)
      #security-team (AppSec only)
      #product-collab (product team)
      #contractors-onboarding (external)
      💡 How to Use Custom Variables
    • Open any role → go to "Customization" tab
    • Edit AWS implementation, integrations, MCP servers, team name, Slack channel
    • Click "Copy from Similar Role" to auto-populate from existing config
    • Export as JSON/Markdown → share with IT team
