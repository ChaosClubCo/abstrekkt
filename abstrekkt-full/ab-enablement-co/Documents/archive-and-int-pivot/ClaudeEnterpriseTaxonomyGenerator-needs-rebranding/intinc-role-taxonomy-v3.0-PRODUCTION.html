❓ How to Use This System
  • Use the search box to find roles by title, department, or level
  • Use filters (Internal/External) to narrow results
  • Click any role to view its configuration
  • Review tabs: Overview, Claude Config, Security, Features, Integrations, Customization
  • Export role as JSON or Markdown for sharing with IT
  • Use "Compare Roles" to see differences between roles
  • Toggle Dark Mode for comfortable reading at night
    • ⚙️ Customization Fields (Per Role)
  • AWS Implementation Details - Customize for your infrastructure
  • Custom Integrations - Add tools specific to your stack
  • MCP Server Access - Configure which MCP servers this role accesses
  • Team/Department Name - Reference for internal organization
  • Slack Channel Integration - Where Claude updates are announced
    • 🚀 Deployment Path
  • Phase 1 (Week 1-4): Manual setup - IT admin reviews configs, distributes to employees
  • Phase 2 (Month 2-3): Optional self-service portal - employees access configs via intranet
  • Quarterly reviews - update configs as roles/org changes
  • Annual security audit - verify compliance (SOC 2, ZDR, audit trails)
