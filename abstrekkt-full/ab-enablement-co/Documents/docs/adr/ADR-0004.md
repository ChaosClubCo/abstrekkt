    _Generated: 2026-06-21. Reconstruction confidence is bounded by accessible project memory/context and the current chat session._


## Status
Accepted for target-state reconstruction.

## Old Direction

## New Direction
Use Supabase Postgres + RLS + pgvector as metadata/provenance/memory layer; raw files stay in storage.

## Alternatives Considered

- Neo4j-first
- Notion database
- File-system search only

## Tradeoffs
Postgres-first is simpler; Neo4j can be added after relationship complexity justifies it.

## Risk Analysis
Vector leakage and privacy risks require scoped retrieval and RLS.

## Migration Impact
Create schema, provenance tables, relationship edges, and review queues.

## Recommended Direction
Supabase-first metadata memory is canonical.
