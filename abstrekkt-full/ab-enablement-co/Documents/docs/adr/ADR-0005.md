## Old Direction
Earlier agents used Claude, GPT-4o, Command R+, OpenRouter, Gemini.

## New Direction
Use provider-agnostic routing with policy constraints; direct provider calls for critical flows, OpenRouter fallback when appropriate.

## Alternatives Considered

- Single-provider
- OpenRouter-only
- Manual prompting only

## Tradeoffs
Flexibility improves resilience; evals prevent quality drift.

## Risk Analysis
Risk is cost runaway and inconsistent outputs; mitigated by budgets, telemetry, evals.

## Migration Impact
Implement agent router config and evaluation framework.
