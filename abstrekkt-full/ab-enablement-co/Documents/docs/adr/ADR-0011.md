# ADR-0011 — Security Posture

    _Generated: 2026-06-21. Reconstruction confidence is bounded by accessible project memory/context and the current chat session._


## Status
Accepted for target-state reconstruction.

## Old Direction
Known incidents include unauthenticated execution and unauthorized budget mutation in adjacent project contexts.

## New Direction
Default deny, RLS-first, signed webhooks, no unauthenticated execution, and human approval for high-impact actions.

## Alternatives Considered

- Trust app-layer auth
- Prototype-open endpoints
- Manual review only

## Tradeoffs
Security adds friction but prevents catastrophic failure.

## Risk Analysis
Risk of slower demos; mitigated by proof-of-value sandboxing.

## Migration Impact
Add threat model, RLS policies, CI checks, and smoke tests.

## Recommended Direction
Security controls are release gates.
