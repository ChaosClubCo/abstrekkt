# Solution Architecture

    _Generated: 2026-06-21. Reconstruction confidence is bounded by accessible project memory/context and the current chat session._


## Revenue Workflow Solution

The core solution turns a lead into a paid audit or workshop. Intake captures goals, systems, pain, budget, urgency, and existing workflows. Qualification enforces the pricing floor and proof-of-value boundary. The audit workspace maps workflows, risks, opportunities, automation candidates, and readiness. Agent analysis drafts findings, but human review approves claims and deliverables.

## Productization Loop

Every engagement emits reusable assets: prompt patterns, workflow maps, use-case catalog entries, dashboard modules, automation recipes, and objection-handling language. These assets are tagged by industry, function, maturity, risk level, and confidence.
