# Repository Boundaries

Current recommendation: one monorepo named `memoir`.

Future split: `memoir-core` for backend/API/database/shared, `memoir-agents` for agents/prompts/workflows, `memoir-studio` for frontend/UX/design-system, `memoir-enterprise` for security/compliance/infrastructure, `memoir-consulting` for business/marketing/research, and `shared-packages` for reusable contracts.

Legacy FlashFusion mapping is one-to-one if future source evidence confirms that brand.
