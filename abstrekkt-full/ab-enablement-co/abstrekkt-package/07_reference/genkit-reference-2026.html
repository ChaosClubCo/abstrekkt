What Genkit is and isn't

Open-source runtime for building production AI agents and features. Not a chatbot wrapper — a typed orchestration framework with observability and middleware baked in.

What Genkit handles for you
  • LLM tool loop orchestration
  • Middleware: retry, fallback, approvals (May 2026)
  • Streaming — regular and durable
  • Distributed tracing + cost tracking
  • RAG: embedders, retrievers, rerankers
  • HITL via Interrupts/Resume
  • Background models (long-running ops)
  • Context caching + sessions
What you still write
  • Prompts and agent decision logic
  • Tool definitions and implementations
  • Business rules and branching conditions
  • State storage (Redis/Supabase for complex flows)
  • Auth and security layer
  • Integration-specific adapters
  • Durable execution (add genkitx-temporal)

Biggest 2026 update — Middleware (May 2026): Programmable interception layer around model calls, tool execution, and generation loops. Inject retries, fallbacks, approvals, and logging without touching application logic. Three layers: Generate (context), Model (reliability), Tool (safety). Live in TypeScript, Go, Dart now. ✓ Pros (2026 updated)
  • Middleware = no-boilerplate reliability
  • Native HITL interrupts/resume
  • Auto-instrumented — zero observability config
  • Type-safe end-to-end (TS + Go 1.0)
  • Built-in RAG + multimodal (text/image/audio/video)
  • Multi-provider: Gemini, Claude, OpenAI, local
  • Deploy anywhere — not Firebase-locked at runtime
  • Temporal plugin for true durable execution
✗ Cons (2026 updated)
  • Python still Beta — no middleware yet
  • Dart still Preview — not production stable
  • Best observability on Google Cloud (export to others = extra work)
  • Complex stateful flows still need Redis/Supabase
  • Young ecosystem vs LangChain's 1,800+ integrations
  • Durable execution requires Temporal plugin (not built-in)
  • Gemini-first docs — Claude/OpenAI examples secondary
  • Middleware overhead adds latency per hop
