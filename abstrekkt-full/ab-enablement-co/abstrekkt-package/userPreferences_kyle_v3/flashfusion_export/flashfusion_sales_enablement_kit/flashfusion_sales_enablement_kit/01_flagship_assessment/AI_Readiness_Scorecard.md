# AI Readiness Scorecard

Score each area from 1 to 5.

1 = unclear / unmanaged / high risk  
3 = partially defined / inconsistent / moderate risk  
5 = clear / documented / low-risk / implementation-ready

| Category | Score | What to inspect | Evidence to collect |
|---|---:|---|---|
| Workflow clarity |  | Is the process documented from trigger to outcome? | SOPs, screenshots, task lists, process notes |
| Ownership |  | Does each step have an accountable owner? | Role list, team assignments, approvals |
| Documentation quality |  | Can a new person follow the process without tribal knowledge? | Playbooks, templates, scripts, examples |
| Data quality |  | Is the data complete, deduplicated, and consistently formatted? | CRM exports, forms, spreadsheets, records |
| Tool maturity |  | Are systems stable and used consistently? | CRM, email, calendar, forms, storage, automations |
| AI usage maturity |  | Are employees using AI consistently and safely? | Tool inventory, prompts, examples, policies |
| Risk level |  | Could automation affect customers, money, legal, HR, or compliance? | Approval requirements, sensitive data, policies |
| Integration feasibility |  | Can the workflow connect to available tools without custom-heavy work? | APIs, Zapier/Make/n8n access, exports, webhooks |
| Measurement readiness |  | Can impact be measured before and after implementation? | Baselines, reports, timestamps, volumes |
| Change readiness |  | Will the team adopt the improved workflow? | Champions, pain level, manager support |

## Score interpretation

40–50: Ready for a focused AI Productivity Sprint.

28–39: Ready after light documentation cleanup and approval mapping.

16–27: Needs workflow clarification before automation.

10–15: Start with documentation and process cleanup, not AI implementation.
