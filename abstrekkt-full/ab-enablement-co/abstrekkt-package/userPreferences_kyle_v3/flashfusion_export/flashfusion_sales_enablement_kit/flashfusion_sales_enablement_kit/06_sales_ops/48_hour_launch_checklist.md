# 48-Hour Launch Checklist

## Day 1 — Package the offer

- [ ] Choose one flagship offer name: **AI Workflow Readiness Assessment**.
- [ ] Choose one pilot price: recommended **$497**.
- [ ] Convert the one-pager into a PDF or publish it as a simple page.
- [ ] Open the fictional HVAC sample report and mark it as “sample only.”
- [ ] Open the Productivity Sprint demo in a browser and rehearse it twice.
- [ ] Add your scheduling link or preferred contact method to the one-pager and landing page.

## Day 1 — Send first five messages

- [ ] Pick five warm contacts.
- [ ] Use `SEND_THIS_FIRST.md` as the base message.
- [ ] Personalize the first sentence for each contact.
- [ ] Record each contact in `04_outreach/outreach_tracker.csv`.
- [ ] Set a follow-up reminder for 3 business days later.

## Day 2 — Publish and repeat

- [ ] Publish the `ai-workflow-readiness-assessment.html` landing page or paste the copy into your current site builder.
- [ ] Send five more warm messages.
- [ ] Post the LinkedIn draft from `06_sales_ops/linkedin_post.md`.
- [ ] Prepare the discovery call script and proposal template.
- [ ] Create a folder for each prospect so you can capture notes cleanly.

## Pass/fail metric

The 48-hour launch is successful if you complete these three things:

1. One offer is public or sendable.
2. Ten warm contacts receive a personalized message.
3. You have a repeatable call flow ready for any reply.

Revenue is the next metric, not the first metric. First, prove that the offer creates conversations.
