# Security Controls Map

Controls map to OWASP ASVS 5.0.0, NIST CSF 2.0, NIST AI RMF, and OWASP Top 10 for LLM/GenAI 2025. Families include authentication, authorization, tenant isolation, audit logging, secrets protection, prompt injection defense, output validation, supply chain, model budgets, and incident response.

## Validation
Security controls must be tested in CI and reviewed before production release.
