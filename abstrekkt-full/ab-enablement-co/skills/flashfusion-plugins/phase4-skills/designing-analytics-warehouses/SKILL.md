## Edge Cases & Anti-Patterns

**Premature optimization** — Don't over-engineer designing analytics warehouses before validating the core approach. Start with the simplest version that could work, then iterate.

**Analysis paralysis** — Perfect data won't arrive. Set a decision deadline with the best available information and document assumptions.

**Stakeholder misalignment** — Ensure all stakeholders agree on success criteria before execution. Misaligned expectations are the #1 cause of "failed" initiatives.

**Ignoring existing work** — Check what already exists at Intinc before building from scratch. Duplicate effort is waste.
