# Planning Accounts

Builds systematic account growth strategies at Intinc — mapping stakeholders, identifying whitespace, and orchestrating expansion plays that grow existing client relationships into larger engagements.

## Quick-Start Decision Tree

```
Request arrives
  ├─ New accounts? ──────── Creation workflow
  ├─ Update existing? ──── Modification workflow
  ├─ Review / audit? ───── Assessment workflow
  ├─ Reporting? ──────────── Analytics & Dashboards
  └─ Issue / escalation? ── Troubleshooting workflow
```

## Usage Examples

**Example 1 — Help me with planning accounts for our top 5 accounts**
→ Pull current state for all 5 accounts → assess each against framework criteria → prioritize by revenue impact → create action plan per account → set review cadence → track progress weekly.

**Example 2 — What's the current status of our planning accounts metrics?**
→ Query CRM for current data → calculate key metrics (conversion rates, velocity, value) → compare against targets and prior period → identify trends → flag items needing attention → generate summary report.

**Example 3 — Improve our planning accounts process — we're losing too many deals**
→ Audit current process end-to-end → identify bottlenecks and drop-off points → benchmark against industry standards → recommend 3-5 specific improvements → estimate impact of each → prioritize by effort/impact → implement top 2 immediately.

## Edge Cases & Anti-Patterns

- **Incomplete data** — Never proceed with planning accounts on assumptions alone. Flag gaps explicitly and get confirmation before continuing.
- **Scope creep** — If the request expands beyond the original planning accounts scope, pause and re-scope rather than absorbing silently.
- **Stakeholder conflict** — When stakeholders disagree on planning accounts approach, document both positions and escalate to decision-maker rather than choosing sides.
- **Compliance overlap** — Check whether planning accounts activities trigger requirements in other compliance frameworks (SOC2, HIPAA, GDPR).
