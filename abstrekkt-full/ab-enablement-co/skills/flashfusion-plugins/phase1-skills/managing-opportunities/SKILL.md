# Managing Opportunities

Drives pipeline discipline at Intinc — enforcing stage-gate criteria, maintaining accurate deal data, and providing the pipeline visibility that enables reliable forecasting.

```
Request arrives
  ├─ New opportunities? ──────── Creation workflow
  ├─ Update existing? ──── Modification workflow
  ├─ Review / audit? ───── Assessment workflow
  ├─ Reporting? ──────────── Analytics & Dashboards
  └─ Issue / escalation? ── Troubleshooting workflow
```

## Usage Examples

**Example 1 — Help me with managing opportunities for our top 5 accounts**
→ Pull current state for all 5 accounts → assess each against framework criteria → prioritize by revenue impact → create action plan per account → set review cadence → track progress weekly.

**Example 2 — What's the current status of our managing opportunities metrics?**
→ Query CRM for current data → calculate key metrics (conversion rates, velocity, value) → compare against targets and prior period → identify trends → flag items needing attention → generate summary report.

**Example 3 — Improve our managing opportunities process — we're losing too many deals**
→ Audit current process end-to-end → identify bottlenecks and drop-off points → benchmark against industry standards → recommend 3-5 specific improvements → estimate impact of each → prioritize by effort/impact → implement top 2 immediately.

## Edge Cases & Anti-Patterns

- **Incomplete data** — Never proceed with managing opportunities on assumptions alone. Flag gaps explicitly and get confirmation before continuing.
- **Scope creep** — If the request expands beyond the original managing opportunities scope, pause and re-scope rather than absorbing silently.
- **Stakeholder conflict** — When stakeholders disagree on managing opportunities approach, document both positions and escalate to decision-maker rather than choosing sides.
- **Compliance overlap** — Check whether managing opportunities activities trigger requirements in other compliance frameworks (SOC2, HIPAA, GDPR).
