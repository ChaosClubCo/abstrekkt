# Discovering Use Cases

Uncovers high-value AI opportunities at client organizations through structured discovery — combining business process analysis with technical feasibility to produce prioritized use case roadmaps.

## Quick-Start Decision Tree

```
Request arrives
  ├─ New use cases? ──────── Creation workflow
  ├─ Update existing? ──── Modification workflow
  ├─ Review / audit? ───── Assessment workflow
  ├─ Reporting? ──────────── Analytics & Dashboards
  └─ Issue / escalation? ── Troubleshooting workflow
```

## Usage Examples

**Example 1 — Scope discovering use cases for a new enterprise prospect**
→ Gather client requirements and constraints → assess technical landscape → map requirements to solution patterns → estimate effort and timeline → identify risks and mitigations → produce deliverable package for client review.

**Example 2 — Improve our discovering use cases methodology based on last quarter's projects**
→ Review all Q-prev engagements using this capability → identify what worked and what didn't → collect feedback from delivery teams and clients → update templates and playbooks → train team on changes → measure improvement in next quarter.

**Example 3 — A client is asking about our discovering use cases capabilities — prepare materials**
→ Pull relevant case studies and references → tailor capability deck to client's industry and size → prepare demo or walkthrough if applicable → anticipate technical questions → prepare competitive positioning → brief sales team.

## Edge Cases & Anti-Patterns

- **Incomplete data** — Never proceed with discovering use cases on assumptions alone. Flag gaps explicitly and get confirmation before continuing.
- **Scope creep** — If the request expands beyond the original discovering use cases scope, pause and re-scope rather than absorbing silently.
- **Stakeholder conflict** — When stakeholders disagree on discovering use cases approach, document both positions and escalate to decision-maker rather than choosing sides.
- **Compliance overlap** — Check whether discovering use cases activities trigger requirements in other compliance frameworks (SOC2, HIPAA, GDPR).
