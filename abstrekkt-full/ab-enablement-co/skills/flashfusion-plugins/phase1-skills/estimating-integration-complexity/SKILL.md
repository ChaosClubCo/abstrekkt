## Edge Cases & Anti-Patterns

- **Incomplete data** — Never proceed with estimating integration complexity on assumptions alone. Flag gaps explicitly and get confirmation before continuing.
- **Scope creep** — If the request expands beyond the original estimating integration complexity scope, pause and re-scope rather than absorbing silently.
- **Stakeholder conflict** — When stakeholders disagree on estimating integration complexity approach, document both positions and escalate to decision-maker rather than choosing sides.
- **Compliance overlap** — Check whether estimating integration complexity activities trigger requirements in other compliance frameworks (SOC2, HIPAA, GDPR).
