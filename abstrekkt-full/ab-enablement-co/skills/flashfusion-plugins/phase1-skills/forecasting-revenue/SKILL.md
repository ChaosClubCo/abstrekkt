# Forecasting Revenue

Produces reliable revenue forecasts at Intinc by combining pipeline-weighted projections with historical close rates and seasonal patterns. Enables confident planning and early warning when targets are at risk.

```
  ├─ Review / audit? ───── Assessment workflow
  ├─ Reporting? ──────────── Analytics & Dashboards
  └─ Issue / escalation? ── Troubleshooting workflow
```

## Usage Examples

**Example 1 — Help me with forecasting revenue for our top 5 accounts**
→ Pull current state for all 5 accounts → assess each against framework criteria → prioritize by revenue impact → create action plan per account → set review cadence → track progress weekly.

**Example 2 — What's the current status of our forecasting revenue metrics?**
→ Query CRM for current data → calculate key metrics (conversion rates, velocity, value) → compare against targets and prior period → identify trends → flag items needing attention → generate summary report.

**Example 3 — Improve our forecasting revenue process — we're losing too many deals**
→ Audit current process end-to-end → identify bottlenecks and drop-off points → benchmark against industry standards → recommend 3-5 specific improvements → estimate impact of each → prioritize by effort/impact → implement top 2 immediately.

## Edge Cases & Anti-Patterns

- **Incomplete data** — Never proceed with forecasting revenue on assumptions alone. Flag gaps explicitly and get confirmation before continuing.
- **Scope creep** — If the request expands beyond the original forecasting revenue scope, pause and re-scope rather than absorbing silently.
- **Stakeholder conflict** — When stakeholders disagree on forecasting revenue approach, document both positions and escalate to decision-maker rather than choosing sides.
- **Compliance overlap** — Check whether forecasting revenue activities trigger requirements in other compliance frameworks (SOC2, HIPAA, GDPR).
