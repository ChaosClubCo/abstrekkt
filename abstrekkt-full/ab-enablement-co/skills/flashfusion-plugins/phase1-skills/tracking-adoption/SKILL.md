# Tracking Adoption

Measures whether Intinc clients are actually using and benefiting from what they purchased — surfacing adoption gaps early so CS can intervene before low usage becomes a churn risk.

## Quick-Start Decision Tree

```
Request arrives
  ├─ New adoption? ──────── Creation workflow
  ├─ Update existing? ──── Modification workflow
  ├─ Review / audit? ───── Assessment workflow
  ├─ Reporting? ──────────── Analytics & Dashboards
  └─ Issue / escalation? ── Troubleshooting workflow
```

## Usage Examples

**Example 1 — Set up tracking adoption for our new enterprise client**
→ Review client profile and contract terms → create customized plan based on their goals → define milestones and success criteria → assign CS resources → schedule initial touchpoints → set up tracking in CS platform.

**Example 2 — Run a tracking adoption review across our book of business**
→ Pull data for all active clients → score each against framework criteria → segment into tiers (healthy, needs attention, at-risk) → create intervention plans for at-risk accounts → brief CS team on findings → schedule follow-up actions.

**Example 3 — Our tracking adoption numbers are declining — diagnose the issue**
→ Pull trend data for last 6 months → segment by client tier, tenure, and service type → identify the cohort driving decline → root cause the top 3 contributing factors → recommend corrective actions → set measurement targets for improvement.

## Edge Cases & Anti-Patterns

- **Incomplete data** — Never proceed with tracking adoption on assumptions alone. Flag gaps explicitly and get confirmation before continuing.
- **Scope creep** — If the request expands beyond the original tracking adoption scope, pause and re-scope rather than absorbing silently.
- **Stakeholder conflict** — When stakeholders disagree on tracking adoption approach, document both positions and escalate to decision-maker rather than choosing sides.
- **Compliance overlap** — Check whether tracking adoption activities trigger requirements in other compliance frameworks (SOC2, HIPAA, GDPR).
