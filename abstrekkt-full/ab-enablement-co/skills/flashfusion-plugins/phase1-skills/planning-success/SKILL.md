# Planning Success

Aligns Intinc delivery with client outcomes through structured success plans — defining what success looks like, tracking milestones, and proving value delivery at every review.

## Quick-Start Decision Tree

```
Request arrives
  ├─ New success? ──────── Creation workflow
  ├─ Update existing? ──── Modification workflow
  ├─ Review / audit? ───── Assessment workflow
  ├─ Reporting? ──────────── Analytics & Dashboards
  └─ Issue / escalation? ── Troubleshooting workflow
```

## Usage Examples

**Example 1 — Set up planning success for our new enterprise client**
→ Review client profile and contract terms → create customized plan based on their goals → define milestones and success criteria → assign CS resources → schedule initial touchpoints → set up tracking in CS platform.

**Example 2 — Run a planning success review across our book of business**
→ Pull data for all active clients → score each against framework criteria → segment into tiers (healthy, needs attention, at-risk) → create intervention plans for at-risk accounts → brief CS team on findings → schedule follow-up actions.

**Example 3 — Our planning success numbers are declining — diagnose the issue**
→ Pull trend data for last 6 months → segment by client tier, tenure, and service type → identify the cohort driving decline → root cause the top 3 contributing factors → recommend corrective actions → set measurement targets for improvement.

## Edge Cases & Anti-Patterns

- **Incomplete data** — Never proceed with planning success on assumptions alone. Flag gaps explicitly and get confirmation before continuing.
- **Scope creep** — If the request expands beyond the original planning success scope, pause and re-scope rather than absorbing silently.
- **Stakeholder conflict** — When stakeholders disagree on planning success approach, document both positions and escalate to decision-maker rather than choosing sides.
- **Compliance overlap** — Check whether planning success activities trigger requirements in other compliance frameworks (SOC2, HIPAA, GDPR).
