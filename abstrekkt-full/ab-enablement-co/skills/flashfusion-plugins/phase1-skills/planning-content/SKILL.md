# Planning Content

Drives strategic content production at Intinc — ensuring every piece of content serves a business objective, maps to the buyer journey, and reinforces Intinc's position as a managed services authority.

## Quick-Start Decision Tree

```
Request arrives
  ├─ New content? ──────── Creation workflow
  ├─ Update existing? ──── Modification workflow
  ├─ Review / audit? ───── Assessment workflow
  ├─ Reporting? ──────────── Analytics & Dashboards
  └─ Issue / escalation? ── Troubleshooting workflow
```

## Usage Examples

**Example 1 — Build a planning content strategy for Q2**
→ Review Q1 performance and learnings → align with Q2 business objectives → define target audience segments → create tactical plan with timeline → set KPIs and measurement framework → allocate budget across activities.

**Example 2 — How did our planning content perform last month?**
→ Pull metrics from all relevant platforms → compile performance dashboard → compare against targets and prior month → identify top performers and underperformers → calculate ROI → recommend optimizations for next month.

**Example 3 — We need to improve our planning content — what should we do differently?**
→ Audit current approach against best practices → benchmark against industry peers → identify 3-5 specific gaps → recommend improvements prioritized by impact → create implementation timeline → set success metrics.

## Edge Cases & Anti-Patterns

- **Incomplete data** — Never proceed with planning content on assumptions alone. Flag gaps explicitly and get confirmation before continuing.
- **Scope creep** — If the request expands beyond the original planning content scope, pause and re-scope rather than absorbing silently.
- **Stakeholder conflict** — When stakeholders disagree on planning content approach, document both positions and escalate to decision-maker rather than choosing sides.
- **Compliance overlap** — Check whether planning content activities trigger requirements in other compliance frameworks (SOC2, HIPAA, GDPR).
