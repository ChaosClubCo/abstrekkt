# Planning Compensation

Ensures Intinc's compensation is competitive, equitable, and aligned with market data — attracting and retaining talent while maintaining responsible cost management.

## Usage Examples

**Example 1 — Help me with planning compensation for the engineering department**
→ Assess current state of planning compensation in engineering → identify gaps against best practices → consult with department leadership on priorities → design program tailored to engineering culture → create implementation plan → set measurement criteria.

**Example 2 — We need a planning compensation program — where do we start?**
→ Conduct needs assessment across the organization → benchmark against companies of similar size → design program framework → pilot with one department → gather feedback and iterate → roll out company-wide with training.

**Example 3 — Review and update our planning compensation process**
→ Document current process end-to-end → gather feedback from participants and stakeholders → identify pain points and compliance gaps → research current best practices → recommend updates → implement changes with proper change management.

## Edge Cases & Anti-Patterns

- **Incomplete data** — Never proceed with planning compensation on assumptions alone. Flag gaps explicitly and get confirmation before continuing.
- **Scope creep** — If the request expands beyond the original planning compensation scope, pause and re-scope rather than absorbing silently.
- **Stakeholder conflict** — When stakeholders disagree on planning compensation approach, document both positions and escalate to decision-maker rather than choosing sides.
- **Compliance overlap** — Check whether planning compensation activities trigger requirements in other compliance frameworks (SOC2, HIPAA, GDPR).
