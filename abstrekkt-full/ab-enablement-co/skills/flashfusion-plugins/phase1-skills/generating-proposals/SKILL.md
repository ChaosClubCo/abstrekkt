# Generating Proposals

Produces professional, winning proposals for Intinc engagements — from managed services contracts to project-based SOWs. Ensures consistent pricing, accurate scoping, and compelling value positioning.

→ Query CRM for current data → calculate key metrics (conversion rates, velocity, value) → compare against targets and prior period → identify trends → flag items needing attention → generate summary report.

## Edge Cases & Anti-Patterns

- **Incomplete data** — Never proceed with generating proposals on assumptions alone. Flag gaps explicitly and get confirmation before continuing.
- **Scope creep** — If the request expands beyond the original generating proposals scope, pause and re-scope rather than absorbing silently.
- **Stakeholder conflict** — When stakeholders disagree on generating proposals approach, document both positions and escalate to decision-maker rather than choosing sides.
- **Compliance overlap** — Check whether generating proposals activities trigger requirements in other compliance frameworks (SOC2, HIPAA, GDPR).
