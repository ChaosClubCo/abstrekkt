# add perplexity

Perplexity can be added as a specialized AI platform in INT Inc.'s enterprise AI strategy, further enhancing both security and operational flexibility alongside existing LLMs like Copilot, Claude, Gemini, and ChatGPT.

### Perplexity: Enterprise Capabilities Overview

- **Enterprise Platform Features:** Perplexity Enterprise Pro and Enterprise Max offer advanced answer engines for real-time research, in-depth analysis, and content generation with full citation support. Enterprise users receive unlimited research/labs queries, access to advanced models (such as o3-pro, Opus 4.1), and Comet Max Assistant for contextual browser-based AI tasks.[^1][^2]
- **Security and Compliance:** Perplexity is SOC 2 Type II certified, adheres to GDPR and PCI DSS, practices strict data retention (7-day deletion default), supports SSO, and implements end-to-end encryption and granular user controls. Data is never used to train Perplexity LLMs, ensuring enterprise trust and privacy.[^3][^4][^5][^6]
- **Integration Ecosystem:** Perplexity provides native integrations for knowledge management (Confluence, Notion), file uploads, workflow automations, and offers the pplx-api for open-source LLM deployment, enabling unified access to Mistral, Llama, and other models. Comet for Enterprise enables seamless task automation directly in the browser environment.[^2][^7]
- **Pricing:** Enterprise Pro and Max tiers offer flexible licensing and admin controls without end-user minimums (previously 50 seats, now can scale organization-wide with one Max seat). Pricing is benchmarked for organizational deployment (details on request), with clear audit logs and management capabilities.[^1]


### Strategic Value to INT Inc.

- **Best-of-Breed Augmentation:** Adding Perplexity to INT Inc.'s stack broadens model selection and improves information retrieval and synthesis, supporting competitive differentiation ("We use the best AI for each job").[^3][^1]
- **Compliance Automation:** With SOC 2 Type II compliance, Perplexity can be safely embedded in workflows that handle sensitive regulatory, client, and audit data, supporting SOC 2/ISO 27001 requirements alongside Claude and Copilot.[^4][^6]
- **Research and Consulting:** Perplexity Enterprise Max's unlimited labs usage accelerates in-depth market analysis, pain-point discovery, and rapid prototyping for INT Inc.'s AI consulting offerings.
- **Cost and Platform Resilience:** The pplx-api enables fast, scalable, cost-efficient inference for open-source models, reducing reliance on individual vendor black-box risks and optimizing operational costs across the AI portfolio.[^7]
