A brand character set requires extra upfront alignment. Gather:

1. **Brand name and tone** (e.g. "Sprout — friendly, educational, 6–10 year old audience")
2. **Number of characters in the set** (typical: 3–6; recommend odd numbers for visual hierarchy)
3. **Shared visual language** — palette, style notes, recurring props or motifs that must appear across all characters
4. **Each character's role and distinguishing feature** (hero, sidekick, antagonist, mentor…)
5. **Intended use** (app UI, merchandise, marketing — affects which angles and expressions to prioritize)

Confirm the full set brief with the user before generating.

Hand off to the **managing-character-sets** skill. It will enforce cross-character consistency rules, generate each character under the Style Lock, and produce a character-set manifest file alongside the renders.
