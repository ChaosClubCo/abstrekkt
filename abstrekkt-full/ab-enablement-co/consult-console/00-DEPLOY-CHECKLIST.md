# Deployment Checklist

Run in order. 🔑 = requires workspace Owner/Primary Owner credentials.

## Phase 0 — Confirm rights (do before anything)
- [ ] Identify the workspace **Primary Owner**. Is it Ryan, Paul, or IT?
- [ ] Confirm seat count and who gets seats (~15 employees; not everyone needs one day one)
- [ ] 🔑 Confirm Team data-training opt-out is in effect (Settings → Privacy). Document it — it's the GSA trust point.

## Phase 1 — Foundation (member-level, no Owner needed)
- [ ] Each member pastes the standard profile block (`org-setup/member-profile-instructions.md`) into Settings → Profile
- [ ] Create the brand voice **Style** (`org-setup/brand-style.md`) and share the definition with members
- [ ] Circulate `org-setup/governance.md` — everyone reads the data rules once

## Phase 2 — Shared projects (member can create; Owner makes them org-shared)
- [ ] Create the six projects (`projects/`)
- [ ] Paste each project's instructions into its Project Instructions field
- [ ] Upload the knowledge inventory items into each project (gather from Ryan first)
- [ ] 🔑 Set projects to **shared** so the whole team sees them

## Phase 3 — Skills (build as member; distribute as Owner)
- [ ] Add the four starter skills (`skills/`)
- [ ] Test each against a real example
- [ ] 🔑 Distribute approved skills org-wide (Organization settings → Skills)

## Phase 4 — Connectors  🔑 Owner for all org-level connections
- [ ] 🔑 Connect Google Workspace **or** Microsoft 365 (whichever United Group runs)
- [ ] 🔑 Connect Slack (if used) for notifications/handoffs
- [ ] CRM + order/warranty system → scope a Zapier/Make bridge (Phase 2 automation work)

## Phase 5 — Enablement
- [ ] Hand each person their role runbook (`enablement/`)
- [ ] Run one 30-minute live walkthrough with Ryan (record it)

## Phase 6 — Measurement
- [ ] Baseline the 3 tasks in `measurement/baseline-tracker.md` BEFORE rollout
- [ ] Re-measure at 2 and 4 weeks → that delta is the Iron Horse case study
