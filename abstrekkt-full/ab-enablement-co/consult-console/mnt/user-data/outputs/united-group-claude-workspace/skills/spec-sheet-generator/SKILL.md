# Spec Sheet Generator

## What this does
Builds clean, accurate spec sheets and comparison tables from the Product Knowledge Base.

## Rules
- Source every spec from the Product Knowledge Base project. No invented numbers.
  Missing value → `[VERIFY]`.
- Use exact series names: 3000 / 4000 / 5000 / Big & Tall.
- Customer/dealer-facing → United Group Style. Lead with the use-environment fit
  (e.g., "built for 24/7 dispatch").

## Steps
1. Confirm which series/models and the audience (customer, dealer, or internal).
2. Pull verified specs; list any gaps as [VERIFY].
3. Format: short benefit intro → spec table → options → warranty line → CTA.
4. Note where a real product photo should drop in.
