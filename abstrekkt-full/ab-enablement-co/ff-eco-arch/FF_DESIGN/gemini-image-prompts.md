## Usage Notes (Gemini Imagen 3 Best Practices)

1. **Lead with intent:** Start each prompt with "Generate an image of..." — Gemini (Imagen 3)
   interprets this as an image generation signal, not a text response request.

2. **Format spec at the end:** Always close with aspect ratio, render quality, and use case.
   Gemini responds well to natural English, not comma-stuffed keywords.

3. **Multi-turn workflow:** For brand consistency across multiple images, establish a base
   prompt (e.g., Prompt 01), then use follow-up prompts to place new elements in that same
   environment. Pass thought signatures in API calls to preserve reasoning context.

4. **No hands rule:** Imagen 3 still struggles with complex hand geometry. Prompts 01–06 and
   08–15 avoid humans intentionally. Prompt 07 uses silhouette framing to sidestep this.

5. **Dark backgrounds:** For dark-background images, explicitly say "pure black (#000000)"
   or "near-black void" — the model defaults toward lighter, more photographic backgrounds.

6. **Resolution note:** Imagen 3 default output is ~1024×1024. For headers and OG images,
   generate square and crop, or specify 16:9 for widescreen assets.
