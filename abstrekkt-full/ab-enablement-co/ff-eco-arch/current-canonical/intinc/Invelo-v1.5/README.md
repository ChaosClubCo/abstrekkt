# INT Inc. - AI Services Website

A professional, high-performance website for INT Inc., an AI services company specializing in pragmatic enterprise solutions.

## 🚀 Quick Start

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```

## 📂 Project Structure
- `src/Home.tsx`: Homepage component.
- `src/About.tsx`: About page component.
- `src/App.tsx`: Root routing configuration.
- `src/components/`: Reusable React components.
- `docs/`: Project documentation (PRD, ARD, Best Practices).

## 📖 Documentation
Detailed documentation can be found in the `/docs` directory:
- [Product Requirements Document (PRD)](./docs/PRD.md)
