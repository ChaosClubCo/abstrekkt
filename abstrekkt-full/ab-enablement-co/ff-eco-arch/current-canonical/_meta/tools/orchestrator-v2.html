What changed from v1
  • Stack swap: ChatGPT → Claude. Prompts are Claude-shaped.
  • Mode-aware: Memoir uses a different prompt than Strategy. Generic doesn't generalize.
  • Adversarial pass is a phase, not a footer. It happens mid-session while you can still respond.
  • Structured log out: insight / next step / drop / counterexample. Markdown export, copy-paste anywhere.
  • Time per phase, not a 60-minute blob. Phase 2 (Dump) gets the largest share; phase 4 (Adversarial) gets second.
Claims · Counterexample · Contradictions

Claims: v2 is more useful than v1 because it removes the "what do I do once I'm in there" gap — modes + prompts + phase timing.

Counterexample: Could be over-structured. The original Wolf Challenge's value was deliberately unstructured journaling; protocolizing it might kill the surprise. If you start sessions and find yourself performing the protocol instead of thinking, the protocol is in the way.

Contradictions: "Adversarial pass at min 30" assumes you'll feel like being challenged then. Sometimes the dump itself is the work and the right phase 4 is rest, not critique. The protocol is a default, not a law.
