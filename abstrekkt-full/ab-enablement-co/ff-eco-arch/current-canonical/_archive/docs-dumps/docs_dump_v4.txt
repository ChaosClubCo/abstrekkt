## Project 1: Career Development & Brag Document

**Archetype**: Your career flywheel → visibility → sponsorship

### The Visibility Equation Explained

**Promotion = Impact × Visibility × Sponsorship**

Think of it like **Netflix recommendations**:
- **Impact** = You made a great movie (necessary but not sufficient)
- **Visibility** = Netflix's algorithm shows it to people (multiplier)
- **Sponsorship** = Critics + celebrities advocate for it (accelerator)

A brilliant movie nobody knows about gets zero views. A mediocre movie widely marketed beats it.

Same with careers. Kyle has high **impact** (automation saves thousands of hours) but medium **visibility**. That's the gap to close.

### Week 2: Promotion Case Framework

**Definition**: A document that answers: "Why should Kyle be promoted to [next level]?"

**Research note**: Most companies require a **promotion packet** with:
1. Self-assessment (how you meet criteria for next level)
2. Impact evidence (metrics, examples, testimonials)
3. Manager narrative (manager's case for you)
4. Peer feedback (360 feedback from cross-functional colleagues)
5. Sponsorship (skip-level/exec says "I see this too")

You build this **over 12 months**, not in the final month before promotion.

#### Step 3: Define Your Promotion Criteria (1 hour)

**Question**: What does your company require for the next level?

**Action**: Get your company's engineering ladder. If they don't have one, use publicly available ones (Google, Meta, Stripe, Etsy ladders are documented).

**What to look for**:

| Level | Typical Criteria |
|---|---|
| Senior | Deep expertise, independent projects, mentors 1-2 people |
| Staff | Breadth across teams, influences direction, prevents silos, drives vision |
| Principal | Organization-wide impact, sets technical strategy, shapes culture |

**Kyle's context** (INT Inc, AppSec + Platform):
- Currently **Staff Engineer** (already at impact level)
- Next move: **Principal** (broader org impact) OR **Staff+ Promotion** (same level, higher compensation)
- 18-month goal: Build case for either direction

**Create a simple matrix**:


  <div class="practice-item">
    <p class="practice-title">3. Specific Instrumentation</p>

  </div>
  
  <div class="practice-item">
    <p class="practice-title">4. Set BPM and Key Explicitly</p>

  <div class="practice-item">
    <p class="practice-title">5. Describe Vocal Character in Detail</p>

  </div>
  
  <div class="practice-item">
    <p class="practice-title">6. Generate 2-3 Variations Per Song</p>
    <p class="practice-desc">Suno often needs multiple attempts. Generate at least 2 versions.</p>
  </div>
  
  <div class="practice-item">
    <p class="practice-title">7. Iterate Based on Output</p>
    <p class="practice-desc">If beat is too bouncy, add "tight, measured" to description. If vocals sound AI, specify "organic delivery."</p>
  </div>
  
  <div class="practice-item">

  </div>
  
  <div class="practice-item">

    <p class="practice-desc">v5 is current and studio-quality. Regenerate from scratch with v5.</p>

    <p class="practice-title">10. Expected Timeline</p>
    <p class="practice-desc">30-60 seconds per track. 3 versions = ~3 minutes. Iterate 2-3x = ~10 minutes total.</p>

function switchTab(tabName) {
  const sections = document.querySelectorAll('.section');
  sections.forEach(s => s.classList.remove('active'));
  document.getElementById(tabName).classList.add('active');
  
  const tabs = document.querySelectorAll('.nav-tab');
  tabs.forEach(t => t.classList.remove('active'));
  event.target.classList.add('active');
}

function toggleCandidate(card) {
  const details = card.querySelector('.candidate-details');
  details.classList.toggle('expanded');
  const toggle = card.querySelector('span:last-child');
  toggle.textContent = details.classList.contains('expanded') ? '−' : '+';
}

function switchSongTab(button, tabId) {
  const tabs = button.parentElement.querySelectorAll('.tab-button');
  tabs.forEach(t => t.classList.remove('active'));
  button.classList.add('active');
  
  const tabsContainer = button.parentElement.parentElement;
  const contents = tabsContainer.querySelectorAll('.tab-content');
  contents.forEach(c => c.classList.remove('active'));
  document.getElementById(tabId).classList.add('active');
}

function copyToClipboard(text, button) {
  navigator.clipboard.writeText(text).then(() => {
    button.classList.add('copied');
    button.textContent = 'Copied!';
    setTimeout(() => {
      button.classList.remove('copied');
      button.textContent = 'Copy ' + (text.includes('[Verse]') ? 'Lyrics' : (text.includes('BPM') ? 'Prompt' : 'Notes'));
    }, 2000);
  });
}
