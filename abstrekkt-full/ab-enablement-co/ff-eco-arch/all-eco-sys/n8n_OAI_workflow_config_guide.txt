n8n OAI WORKFLOW CONFIGURATION GUIDE
Status: All 7 workflows need HTTP Request nodes wired before activation

================================================================================
WHAT THESE WORKFLOWS DO
================================================================================

All 7 OAI workflows follow the same pattern:

  Schedule Trigger → HTTP Request (READ) → Code (filter/process) → HTTP Request 1 (WRITE/DELETE)

They are operational automation for the Fusion AI platform — keeping data clean,
tokens reset, health scores current. They all call the Base44 API for the
Fusion AI app (id: 68dd8e79ca073475565c8e16).


================================================================================
BASE44 API CONFIGURATION (same for all 7 workflows)
================================================================================

How to Get Your Base44 API Key:
  1. Open Base44: https://app.base44.com/apps/68dd8e79ca073475565c8e16
  2. Go to Settings → API (or the developer panel)
  3. Copy the API key / bearer token

Base44 REST API Format:
  Base URL:      https://api.base44.com/v1/apps/68dd8e79ca073475565c8e16
  Auth:          Bearer {your_base44_api_key}
  Content-Type:  application/json

Entity endpoints follow this pattern:
  GET    /entities/{EntityName}         → list all records
  GET    /entities/{EntityName}/{id}    → get one record
  POST   /entities/{EntityName}         → create record
  PUT    /entities/{EntityName}/{id}    → update record
  DELETE /entities/{EntityName}/{id}    → delete record

1. OAI Data Retention Purge   (workflow id: JErzPwjEoqxgMRUR)
--------------------------------------------------------------------------------
Schedule:  Nightly 2AM
Purpose:   Cleans AuditEvent, WorkflowExecution, ExecutionCostRecord based
           on retention_days setting.

HTTP Request (node 1) — READ:
  Method:  GET
  URL:     https://api.base44.com/v1/apps/68dd8e79ca073475565c8e16/entities/DataRetentionPolicy

  URL:     https://api.base44.com/v1/apps/68dd8e79ca073475565c8e16/entities/{{ $json.entityType }}/{{ $json.id }}
  Auth:    Bearer token header

================================================================================

  2. Get your Base44 API key from the Fusion AI app settings.

  3. Create an n8n Credential:

       - Name:         Base44 Fusion AI
       - Header Name:  Authorization

  4. For each workflow:
       - Open the workflow
       - Click HTTP Request node → paste URL from this guide → select the
         "Base44 Fusion AI" credential
       - Click HTTP Request 1 node → paste URL → select same credential
       - Click Activate (publish button)

  5. Verify first execution completes without error.
