# Claude Enablement — Session Timing Guide
**For: Facilitators (Kyle / INT staff)**
*Version 1.0 — May 2026*

---

## Session Formats

| Format | Total Time | Use When |
|---|---|---|
| **Express** | 30 min | Tech-savvy employee, repeat offender, just needs setup help |
| **Standard** | 60 min | Most employees — recommended default |
| **Full** | 90 min | Skeptical employee, exec needing ROI framing, multiple use cases to cover |

---

## Express Session — 30 Minutes

| Phase | Minutes | What happens | Hard stop |
|---|---|---|---|
| Pre-brief | Before | Review intake form, load prompt package | — |
| Login + Plan check | 0–3 | Confirm they're on Pro, not Free | 3 min |
| Projects setup | 3–12 | Name project, write 3-line instructions, test | 9 min |
| Prompt package delivery | 12–20 | Walk through 2–3 prompts, have them run one live | 8 min |
| QC gate | 20–27 | Run q1–q4 (critical items only) | 7 min |
| Next session | 27–30 | Set date, identify #1 use case | 3 min |

**What gets cut:** Memory configuration, connectors, extended features. Cover these in session 2.

**Facilitator note:** If instructions test fails (Test 1 or 2), stop and fix it — don't move to prompts with broken setup. Extend to Standard if needed.

---

## Standard Session — 60 Minutes

| Phase | Minutes | What happens | Hard stop |
|---|---|---|---|
| Intake review | 0–3 | Confirm role, goals, current pain points | 3 min |
| Login + Plan check | 3–7 | Confirm Pro plan; if Free, address upgrade path | 4 min |
| Mental model (Projects) | 7–12 | "Claude has amnesia without a Project." Demo the difference. | 5 min |
| Projects setup | 12–25 | Name, write instructions (use template), test all 3 QC checks | 13 min |
| Memory configuration | 25–30 | Enable memory, write 3 memory edits live | 5 min |
| Prompt package delivery | 30–45 | Walk through all 6 prompts, run 2 live | 15 min |
| Connector setup | 45–52 | Connect 1 relevant tool (Drive, Notion, Teams) | 7 min |
| QC gate + gaps | 52–58 | Run all 7 QC items, log any fails as open gaps | 6 min |
| Next session + use case | 58–60 | Confirm #1 weekly use case, set date | 2 min |

**Facilitator note:** Projects setup is the make-or-break phase. Don't rush it. If you're behind by the Memory phase, cut connectors, not Projects.

**Most common time sinks:**
- Instructions test failing → employee had to rewrite twice (add 5–8 min)
- Employee has never used Claude before → mental model phase needs 2 extra minutes
- Wrong plan (Free) discovered mid-session → pause and address upgrade immediately, don't work around it

---

## Full Session — 90 Minutes

| Phase | Minutes | What happens | Hard stop |
|---|---|---|---|
| Intake deep-dive | 0–5 | Role, goals, specific pain points, tool stack | 5 min |
| Login + Plan check | 5–10 | Plan confirmation; if exec, address team/enterprise upgrade path | 5 min |
| Mental model (Projects + Memory) | 10–18 | Full "before/after" demo — show Claude without setup vs. with | 8 min |
| Projects setup | 18–33 | Name, write detailed instructions, test all 3 QC checks, iterate if needed | 15 min |
| Memory configuration | 33–40 | Enable, write 5 memory edits, verify in new conversation | 7 min |
| Prompt package delivery | 40–58 | Walk through all 6 prompts, run 3 live, customize 1 together | 18 min |
| Connector setup | 58–68 | Connect 2–3 relevant tools, test 1 live query | 10 min |
| Advanced feature preview | 68–78 | Artifacts, Deep Research, or extended thinking (based on role) | 10 min |
| QC gate | 78–86 | All 7 items; any fails become next session agenda | 8 min |
| Next session + use case | 86–90 | Set date, confirm 3-week focus plan | 4 min |

**Facilitator note:** Full sessions work best when the employee has a specific skepticism or complex use case. Don't default to this for everyone — it's fatiguing.

---

## Between-Session Cadence

| Week | Employee action | Facilitator action |
|---|---|---|
| Week 1 (post-session) | Completes self-service guide, bookmarks accountability tracker | Sends prompt package reminder if not acknowledged |
| Week 2 | First accountability check-in | Reviews check-in before week 3 |
| Week 3 | Second check-in | Prep for session 2; focus on open gaps from QC |
| Week 4 | Session 2 | Log outcome, update QC gate |
| Month 2+ | Weekly check-ins | Monthly health report for leadership |

---

## When to Stop and Reschedule

Stop the session and reschedule if:
- Employee is on a Free plan and can't or won't upgrade — nothing material can be set up
- Employee's computer/IT environment blocks claude.ai (corporate proxy issue) — IT must fix first
- Employee is actively disengaged or hostile — pause, flag to manager, resume when framing is addressed
- Session has gone 20% over time with major phases unfinished — better to do two clean sessions than one rushed one

---

## The Three Things That Must Happen in Every Session

These are non-negotiable regardless of format. Everything else is optional.

1. **Project with working custom instructions** — tested, not just created
2. **One prompt package prompt run live** — they typed it, they saw it work
3. **Next session date confirmed** — on the calendar before they leave

Without all three, the session did not succeed. Log as "Needs Follow-up."
