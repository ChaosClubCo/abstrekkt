Hard rules vs. FlashFusion: No gradient strokes. No neon bloom. No glass blur. Border radius stays 8px. Font stack stays Inter + JetBrains Mono. Backgrounds stay #0f0f0f / #1a1a1a. Icons are semantic brand pillars — human, community, growth, cycles, progress, safety, voice, ritual — not generic product navigation.
Context of useimplementation guidance for CC landing, cards, editorial layouts, and community surfaces
Tier 1 · Glyph box
Pillar cards and feature sections
Use for high-signal cards where the icon anchors the section. Keep the 52×52 well in marketing surfaces; use 44×44 only inside dense dashboards.
Tier 2 · Flat accent
Lists, editorial markers, compact callouts
Use the raw 24×24 outline icon without a box. Rotate red → orange → amber only when grouped; otherwise choose the accent semantically.
No Tier 3
No decorative icon treatment
If the icon needs a glow, mask, gradient, bevel, or 3D shell to feel interesting, the surrounding composition is doing the wrong job.
