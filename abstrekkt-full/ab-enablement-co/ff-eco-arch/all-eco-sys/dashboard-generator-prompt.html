Dashboard Generator Prompt

Production-ready context prompt for building enterprise integration dashboards

Overview

Purpose: This prompt template generates secure, production-ready dashboards that integrate with HubSpot, Freshdesk, Notion, AI platforms (Gemini/Claude/OpenAI/Google AI Studio), GitHub, Zapier, n8n, and custom APIs.

Key Features

  • ✅ Multi-platform integration (10+ services out-of-box)
  • ✅ Security-first (OWASP Top 10, SOC2 compliant)
  • ✅ Extensible plugin system (add custom integrations)
  • ✅ Production-ready patterns (rate limiting, caching, error handling)
  • ✅ Real-time & polling modes (WebSockets + HTTP)
  • ✅ Observable (Sentry errors + PostHog analytics)

## 4. Security Checklist (Pre-Flight Validation)
Before generating code, verify:
- [ ] **A01: Access Control** — RLS enforced (`user_id = auth.uid()`)
- [ ] **A02: Sensitive Data** — No API keys in client code (server-side only)
- [ ] **A03: Injection** — All API params validated (zod schemas)
- [ ] **A04: Rate Limiting** — Per-integration limits enforced (exponential backoff)
- [ ] **A05: Webhook Security** — HMAC verification for all inbound webhooks
- [ ] **A06: Error Leakage** — No stack traces in UI (log to Sentry)
- [ ] **A07: Audit Trail** — All API calls logged (90-day retention)
- [ ] **A08: PII Handling** — Mask emails/phones in UI, encrypted at rest
- [ ] **A09: Token Rotation** — OAuth refresh tokens rotated every 6hrs
- [ ] **A10: Timeout Handling** — All requests timeout after 10s (configurable)

# CRITICAL CONSTRAINTS
1. **Never concatenate user input into API URLs** (injection risk)
2. **Always verify webhook signatures** (HMAC/JWT, never trust source IP alone)
3. **Log all integration errors to Sentry** (with sanitized context, no secrets)
4. **Cache aggressively** (5min default, Redis for shared cache)
5. **Fail gracefully** (1 integration down ≠ entire dashboard fails)
6. **Rate limit proactively** (don't wait for 429, track locally)
7. **Rotate OAuth tokens** (refresh 1hr before expiry)
8. **Mask PII in UI** (emails → e***@example.com, phones → (***) ***-1234)
9. **Timeout all requests** (10s default, 30s max for AI APIs)
10. **Audit trail everything** (who, what, when, source IP, 90-day retention)

# OUTPUT FORMAT
Deliver as:
1. **Dashboard.tsx** (main component)
2. **/lib/integrations/{service}.ts** (one file per integration)
3. **/lib/types.ts** (shared TypeScript interfaces)
4. **/lib/errors.ts** (error handling utilities)
5. **README.md** (setup instructions, env vars, testing)
6. **.env.example** (all required API keys/tokens, NO actual secrets)
7. **docker-compose.yml** (if using Redis cache)

# TESTING REQUIREMENTS
Include:
- **Happy path:** All integrations return data successfully
- **Partial failure:** HubSpot succeeds, Freshdesk fails (dashboard still works)
- **Rate limit:** Exponential backoff works (1s, 2s, 4s, 8s, 16s max)
- **Webhook verification:** Invalid HMAC rejected
- **Timeout:** Request aborted after 10s
- **PII masking:** Email displayed as `e***@example.com`

import { z } from 'zod';

const HubSpotConfigSchema = z.object({
  accessToken: z.string(),
  refreshToken: z.string(),
  expiresAt: z.number(),
});

export class HubSpotConnector {
  private config: z.infer;
  private baseUrl = 'https://api.hubapi.com';

  constructor(config: unknown) {
    this.config = HubSpotConfigSchema.parse(config);
  }

  async fetchDeals(params: { limit?: number } = {}) {
    // Check token expiry, refresh if needed
    if (Date.now() >= this.config.expiresAt - 3600000) {
      await this.refreshAccessToken();
    }

    const response = await fetch(
      `${this.baseUrl}/crm/v3/objects/deals?limit=${params.limit || 100}`,
      {
        headers: {
          'Authorization': `Bearer ${this.config.accessToken}`,
        },
        signal: AbortSignal.timeout(10000), // 10s timeout
      }
    );

      throw new Error(`HubSpot API error: ${response.status}`);

      id: deal.id,
      source: 'hubspot',
      label: 'Deal',
      value: deal.properties.amount,
      timestamp: new Date(deal.properties.createdate),
    }));
  }

Freshdesk Integration

// lib/integrations/freshdesk.ts
export class FreshdeskConnector {
  private apiKey: string;
  private domain: string;

  constructor(config: { apiKey: string; domain: string }) {
    this.apiKey = config.apiKey;
    this.domain = config.domain;
  }

  async fetchTickets(params: { status?: string } = {}) {
    const auth = Buffer.from(`${this.apiKey}:X`).toString('base64');
    
    const response = await fetch(
      `https://${this.domain}.freshdesk.com/api/v2/tickets?status=${params.status || 'open'}`,
      {
        headers: {
          'Authorization': `Basic ${auth}`,
        },
        signal: AbortSignal.timeout(10000),
      }
    );

    if (!response.ok) {
      throw new Error(`Freshdesk API error: ${response.status}`);
    }

    const tickets = await response.json();
    return tickets.map(ticket => ({
      id: ticket.id,
      source: 'freshdesk',
      label: 'Ticket',
      value: ticket.subject,
      timestamp: new Date(ticket.created_at),
    }));
  }
}

AI Platform Integration (Gemini/Claude/OpenAI)

// lib/integrations/ai-platform.ts
export class AIPlatformConnector {
  private apiKey: string;
  private provider: 'gemini' | 'claude' | 'openai';
  private costTracker: CostTracker;

  async generateCompletion(prompt: string, options: CompletionOptions) {
    // 5-layer LLM safety
    const sanitizedPrompt = this.validateInput(prompt);
    const structuredPrompt = this.separateInstructionsFromData(sanitizedPrompt);
    
    const response = await this.callAPI(structuredPrompt, options);
    
    const filteredOutput = this.filterOutput(response);
    const monitored = await this.logInteraction(prompt, filteredOutput);
    
    // Track cost
    await this.costTracker.track({
      userId: options.userId,
      tokensUsed: response.usage.total_tokens,
      costUSD: this.calculateCost(response.usage),
    });

    // Alert if over budget
    if (monitored.costExceeded) {
      await this.alertBudgetExceeded(options.userId);
    }

    return filteredOutput;
  }

  private validateInput(input: string): string {
    // Max length, pattern check, injection detection
    if (input.length > 10000) throw new Error('Input too long');
    if (this.detectInjection(input)) throw new Error('Injection detected');
    return input;
  }

  private calculateCost(usage: { prompt_tokens: number; completion_tokens: number }): number {
    const rates = {
      gemini: { input: 0.000125, output: 0.000375 },
      claude: { input: 0.003, output: 0.015 },
      openai: { input: 0.0015, output: 0.002 },
    };
    
    const rate = rates[this.provider];
    return (usage.prompt_tokens * rate.input + usage.completion_tokens * rate.output) / 1000;
  }
}

Security Hardening

CRITICAL: All security measures are mandatory. Never skip validation, never trust client input, never log secrets.

OWASP Top 10 Checklist

  • A01: Access Control — RLS verified, users can't see others' data
  • A02: Misconfiguration — No defaults, buckets locked (private by default)
  • A03: Injection — All queries parameterized, no string concatenation
  • A04: Insecure Design — Rate limits in place, threat model reviewed
  • A05: Cryptography — TLS enforced, PII encrypted at rest, no plaintext secrets
  • A09: Supply Chain — Deps scanned (npm audit), lockfile committed
  • Input validation — Whitelist (not blacklist), type-check, length bounds
  • Output validation — No stack traces in errors, sanitize external responses
  • Secrets — Env vars only, rotated quarterly
  • Audit trail — Logs immutable, 90-day retention minimum

Webhook Verification

TypeScript 
// lib/webhooks/verify.ts
import crypto from 'crypto';

export function verifyHubSpotWebhook(
  payload: string,
  signature: string,
  secret: string
): boolean {
  const hash = crypto
    .createHmac('sha256', secret)
    .update(payload)
    .digest('hex');
  
  // Timing-safe comparison prevents timing attacks
  return crypto.timingSafeEqual(
    Buffer.from(signature),
    Buffer.from(hash)
  );
}

// API route usage
export default async function handler(req, res) {
  const signature = req.headers['x-hubspot-signature'];
  const payload = JSON.stringify(req.body);
  
  if (!verifyHubSpotWebhook(payload, signature, process.env.HUBSPOT_WEBHOOK_SECRET)) {
    return res.status(401).json({ error: 'Invalid signature' });
  }
  
  // Process webhook...
}

PII Masking

TypeScript 
// lib/privacy.ts
export function maskEmail(email: string): string {
  const [local, domain] = email.split('@');
  if (!local || !domain) return '***';
  return `${local[0]}***@${domain}`;
}

export function maskPhone(phone: string): string {
  const digits = phone.replace(/\D/g, '');
  if (digits.length < 4) return '***';
  return `(***) ***-${digits.slice(-4)}`;
}

export function maskSSN(ssn: string): string {
  const digits = ssn.replace(/\D/g, '');
  if (digits.length !== 9) return '***-**-****';
  return `***-**-${digits.slice(-4)}`;
}

TypeScript 
// User-provided config via UI
const customCRMPlugin: IntegrationPlugin = {
  id: 'custom_crm_v1',
  name: 'Custom CRM',
  description: 'Internal sales tracking system',
  icon: '📊',
  category: 'crm',
  
  authType: 'apiKey',
  authConfig: {
    apiKey: { headerName: 'X-API-Key' },
  },
  
  baseUrl: 'https://api.mycompany.com',
  rateLimits: { requests: 100, window: 'minute' },
  
  endpoints: {
    deals: {
      path: '/v1/deals',
      method: 'GET',
      params: { status: 'string', limit: 'number' },
      response: 'json',
    },
  },
  
  async onAuth(credentials) {
    const response = await fetch(`${this.baseUrl}/v1/test`, {
      headers: { 'X-API-Key': credentials.apiKey },
    });
    return response.ok;
  },
  
  async onFetch(query) {
    const response = await fetch(`${this.baseUrl}/v1/deals?status=open`, {
      headers: { 'X-API-Key': query.credentials.apiKey },
    });
    const data = await response.json();
    return this.transformResponse(data);
  },
  
  transformResponse(raw: any) {
    return raw.deals.map((deal: any) => ({
      id: deal.id,
      source: 'custom_crm_v1',
      label: 'Open Deals',
      value: deal.amount,
      unit: 'currency',
      timestamp: new Date(deal.updated_at),
    }));
  },
  
  onError(error) {
    if (error.message.includes('401')) {
      return {
        source: 'custom_crm_v1',
        cause: 'Invalid API key',
        fix: 'Re-authenticate in Settings → Integrations',
        retryable: false,
      };
    }
    return {
      source: 'custom_crm_v1',
      cause: error.message,
      fix: 'Check logs for details',
      retryable: true,
    };
  },
};

// Register plugin
import { registry } from './registry';
registry.register(customCRMPlugin);

Pre-Deployment Checklist

Before production: Verify ALL items. Missing any item = security vulnerability or reliability issue.

Security

  • All API keys in .env (never hardcoded)
  • RLS policies enforced in database
  • Webhook signatures verified (HMAC)
  • Rate limiting configured (per-user + per-integration)
  • PII masked in UI (emails, phones, SSNs)
  • Audit logging enabled (90-day retention)
  • Error messages sanitized (no stack traces to users)
  • OAuth token refresh automated
  • Dependencies scanned (npm audit, Snyk)
  • HTTPS enforced (no HTTP fallback)

Reliability

  • Error boundaries per integration
  • Exponential backoff on retries (1s, 2s, 4s, 8s, 16s max)
  • Circuit breaker implemented (5 failures → open)
  • Timeouts configured (10s default, 30s for AI)
  • Caching enabled (5min default, Redis)
  • Graceful degradation (1 service down ≠ all fail)
  • Health checks configured (/api/health endpoint)
  • Monitoring alerts configured (Sentry + Slack)

Performance

  • API calls parallelized (Promise.allSettled)
  • Pagination implemented (100 records/page max)
  • Database queries optimized (indexes on foreign keys)
  • Client-side state managed (SWR/TanStack Query)
  • Images optimized (WebP, lazy loading)
  • Bundle size checked (<200KB initial)

Testing

  • Unit tests (>80% coverage)
  • Integration tests (happy path + error cases)
  • E2E tests (critical user flows)
  • Load tests (100 concurrent users)
  • Security tests (OWASP ZAP scan)

Documentation

  • README.md (setup, env vars, testing)
  • .env.example (all required vars)
  • API docs (OpenAPI/Swagger)
  • Architecture diagram (Mermaid/draw.io)
  • Runbook (common issues + fixes)
