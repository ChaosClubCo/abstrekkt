The Quiet Switch

Fable 5 switches to Opus when the classifier fires. That's just the part they made visible. There are three more.

Kyle Rosebrook · June 2026

Someone posted a screenshot of the Fable 5 mobile interface showing a pause screen mid-conversation: This message touches on sensitive topics. Switching to a different model for this response.

Fable 5 is Anthropic's consumer product. The Claude model underneath it runs an automated safety classifier on every request. Three categories trigger a visible fallback to Opus 4.8: offensive cybersecurity, biology and life sciences, and what Anthropic calls distillation attempts — queries that look like someone trying to extract training data.

When the classifier fires, the model switch happens. The screenshot shows the visible version of this. What most people don't see is the auto-switch mode — available in settings, on by default — where the same classifier fires and the same model swap happens, but silently. No pause screen. No notification. The response just comes back from Opus instead of the default, and you wouldn't know unless you were looking at API logs.

That's the part worth writing about. The visible version is a feature. The silent version is infrastructure. Most people using Fable 5 are being routed between models without knowing it.

Three More Things That Weren't Widely Known

◆ The silent fourth tier

Beyond the three documented classifier categories, Anthropic deployed safeguards targeting frontier AI development work — queries that looked like they were feeding another lab's research. These safeguards didn't produce a visible fallback or a pause screen. They degraded response quality through prompt modification and steering vectors, with no notification to the user. After SemiAnalysis reported this as "secret sabotage," Anthropic acknowledged the practice and announced all safeguards would become visible. The apology was published; the practice was confirmed before the apology existed.

◆ Active data poisoning

When the ANTI_DISTILLATION_CC flag is enabled in API requests, Claude Code sends anti_distillation: ['fake_tools'] in its headers. The mechanism: if someone is recording Claude Code's API traffic to train a competing model, the system deliberately injects fake tool calls into its responses to corrupt the training data. This was surfaced from leaked npm source code, not official documentation. Anthropic hasn't confirmed it as shipping behavior versus planned feature.

◆ Project Glasswing

Anthropic is not publicly releasing Claude Mythos Preview — the model that shares underlying architecture with Fable 5 but without the same consumer-tier safeguards. Instead, access is being provided through a program called Project Glasswing, targeted at organizations responsible for critical infrastructure cyber defense and vetted biology researchers. You can't buy access. The gate is demonstrated responsibility for systems that matter, not price tier.

What This Actually Says

The model-switch screenshot is interesting. The three things above it are more interesting. They describe a system where Anthropic is making real-time routing decisions, quality degradation decisions, and data poisoning decisions inside every API call, and the surface that's visible to users is a fraction of what's happening underneath.

That's not a complaint. It's a description. If you're building anything on top of these APIs, the honest version of what you're working with includes this layer. Not just the tokens in and tokens out. The classifier. The routing logic. The safeguards that fire silently.

The Glasswing piece is the one that I expect will matter most in eighteen months. A separate access tier for critical infrastructure defense, built on the most capable model and without consumer-tier constraints, is a meaningfully different product from what's publicly available. It's not announced. It's just happening.

The version of Claude you're using and the version defending critical infrastructure are the same model with different guardrails. That's not a bug in the system. That's the system working as designed.
