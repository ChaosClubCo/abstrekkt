Build Guide

Prompt templates for extending the B44 INTeract platform across three build phases.

Phase 1 — MVP

Creation prompt

Role: Expert full-stack developer.

  • Admin dashboard: protected login, activity library, event scheduler, participation tracking
  • Activity library: CRUD (title, description, duration, type, instructions)
  • Event scheduler: calendar, timezone picker, magic link generation
  • Participant portal: magic-link access, photo upload, polls, text submissions
  • Analytics: participation rates, ratings, attendance trends

Data models: Users · Activities · Events · Participation · Feedback · Assets

Phase 2 — AI

AI features prompt
  • Rule-based: holiday triggers, variety balancing, engagement gap alerts
  • LLM-powered: feedback sentiment, custom activity generator, scheduling patterns
  • UI: Suggestions widget (3–5 items with reasoning)
  • Persist accept/reject for preference learning

Phase 3 — Notifications

Webhook prompt
  • Outbound POST on: scheduled, 24h reminder, post-event recap
  • Teams Adaptive Cards with RSVP button
  • Settings: webhook URL + notification toggles + template editor
  • .ics generation for Outlook sync

Best practices

  • First prompt: comprehensive — include all models, roles, workflows
  • One feature per follow-up to prevent regressions
  • Define state machines: Draft → Scheduled → Active → Completed
  • Request mobile explicitly — not assumed

Prompting Guide

Frameworks for getting quality outputs when building or extending this platform.

RACE — Feature requests

Role → Action → Context → Expectations

Example — photo gallery
Role: Full-stack developer on engagement platform.
Action: Add photo gallery to post-event recap.
Context: Recap shows stats + text only. Activities generate lots of photos.
Expectations: Drag-drop upload, thumbnail grid, lightbox, admin moderation, mobile camera access.

APE — Problem solving

Example — participation rates
Ask: How do we increase RSVP-to-attendance conversion?
Plan: Identify friction → add social proof → better reminders → gamify consistency
Execute: One-click RSVP in Teams message, "14 teammates joined", 1h reminder, streak tracking.

Tips

  • Explicit data: "RSVPs as many-to-many between Users and Events"
  • Specify roles: "Admin: full CRUD. Participants: read-only except submissions."
  • Validation rules: "Event date must be future. Duration 5–120 min."
  • Error states: "If magic link expired, show message + upcoming events link."

Teams Integration

Connect B44 to Microsoft Teams using Incoming Webhooks.

Setup

  1. Open Teams channel → More options → Connectors → Incoming Webhook.
  2. Configure → name it → Create → copy URL.
  3. Paste URL into B44 Settings → Integrations → Teams Webhook.

Platform Features

Reference for the full B44 INTeract feature set.

Core

  • Activity library with CRUD, types, duration, interaction modes
  • Event scheduler: Draft→Scheduled→Active→Completed, magic links, recurring series
  • Participant portal: no-login magic link access, polls, photo uploads, quizzes
  • Teams/Slack webhooks with Adaptive Cards and Block Kit

Gamification

  • Points, tiers (Bronze→Platinum), badges with rarity levels
  • Configurable rules engine with cooldowns and monthly caps
  • Leaderboards (global, team, skill, challenge)
  • Reward store with approval workflows, charitable donations, virtual items

AI features

  • Activity recommendations (rule-based + LLM)
  • Feedback sentiment analysis
  • Burnout risk detection and coaching insights
  • Predictive engagement analytics
  • Gamification A/B testing

Social + recognition

  • Peer recognition with categories, moderation, AI-flagging
  • Channels + direct messages
  • Mentorship matching, buddy system
  • Milestone celebrations (birthdays, anniversaries)

Analytics

  • Team analytics, cohort analysis, AnalyticsSnapshots
  • Lifecycle state tracking (New→Activated→Engaged→Power User→At Risk→Dormant)
  • A/B test framework with statistical significance tracking
