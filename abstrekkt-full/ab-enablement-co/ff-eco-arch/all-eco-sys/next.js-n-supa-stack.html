Technical Summary

Next.js & Supabase Enterprise Stack

A robust, type-safe full-stack application architecture built for scale. Utilizing the Next.js App Router, tRPC for end-to-end type safety, and Supabase for real-time data and authentication.

Security First

Row Level Security (RLS) is baked into every PostgreSQL table, ensuring user isolation at the data layer.

tRPC Type-Safety

Zero-API-overhead. Share TypeScript types seamlessly between your backend routers and React components.

CI/CD Driven

Automated deployment via GitHub Actions to Vercel, with pre-deployment linting, formatting, and unit testing.

Quick Start

1. Local Setup

Clone the repository and install dependencies:

git clone https://github.com/project/repo.git
cd repo
npm install

2. Environment Configuration

Copy .env.example to .env.local and fill in your Supabase credentials:

NEXT_PUBLIC_SUPABASE_URL=your-project-url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key

Core Configuration

.github/workflows/deploy.yml

name: Deploy to Vercel
on:
  push:
    branches: [main]
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Install Dependencies
        run: npm ci
      - name: Run Tests
        run: npm test
      - name: Deploy
        uses: amondnet/vercel-action@v20

Database Architecture

Row Level Security Notice

Every table in this schema implements strict RLS. Users can only perform CRUD operations on records associated with their auth.uid(). Public access is disabled by default.

-- Create projects table
CREATE TABLE projects (
  id uuid PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id uuid REFERENCES auth.users(id) NOT NULL,
  name text NOT NULL,
  description text,
  created_at timestamp with time zone DEFAULT now()
);

-- Enable RLS
ALTER TABLE projects ENABLE ROW LEVEL SECURITY;

-- Create Policy
CREATE POLICY "Users can manage their own projects"
ON projects FOR ALL
USING (auth.uid() = user_id);
