## COPY/PASTE INPUT BLOCK

```

Convert my rough feature notes into a complete PRD with MVP scope lock, explicit non-goals, and measurable success criteria.

CONTEXT:
- Product type: B2B SaaS feature or standalone app capability
- Target: spec-driven development with minimal ambiguity

CONSTRAINTS:
- Prefer shipping over perfection; defer non-essential items into backlog
- Include security/privacy considerations and analytics events
- No placeholders; include concrete examples

INPUTS:
[Paste: feature notes, target users, existing constraints, and any current UI links]

OUTPUT NEEDS:
- Markdown
- Sections: Problem; Users; Jobs-to-be-done; MVP scope; Non-goals; Requirements; UX flows; Data model; API contracts; Telemetry; Risks; Rollout plan; ACCEPTANCE CRITERIA; CLAIMS CHECK

MODE SWITCHES:
- ReasoningEngine=FirstPrinciples
- Framework=CO-STAR
- OutputFormat=Markdown
```

## USAGE NOTES

- Replace bracketed text with your raw feature ideas and user research
- FirstPrinciples reasoning rebuilds the feature from core needs
- CO-STAR framework ensures context, objective, style, tone, audience, response alignment
