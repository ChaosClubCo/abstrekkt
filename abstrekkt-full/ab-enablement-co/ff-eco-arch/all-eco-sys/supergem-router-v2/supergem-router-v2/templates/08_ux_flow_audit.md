# Template 8: UX Flow Audit (Friction Map + Fix Spec)

## COPY/PASTE INPUT BLOCK

```
GOAL:
Audit the described user flow and output a friction map plus a prioritized fix spec that engineers can implement.

CONTEXT:
- Target: conversion and task completion
- Include accessibility and mobile-first behaviors

CONSTRAINTS:
- Recommendations must be implementable with clear UI changes
- Include a11y checks (WCAG AA for web)

INPUTS:
[Paste: flow steps, screenshots/descriptions, and target persona]

OUTPUT NEEDS:
- Markdown
- Sections: Flow map; friction points; usability heuristics; accessibility issues; fix spec; measurement plan; CLAIMS CHECK

MODE SWITCHES:
- ReasoningEngine=TreeOfThoughts
- Framework=CO-STAR
- OutputFormat=Markdown
```

## USAGE NOTES

- Paste your user flow steps and any screenshots or descriptions
- TreeOfThoughts explores multiple UX improvement paths
- CO-STAR ensures output matches audience (engineers + designers)
- Output includes WCAG AA compliance checks
