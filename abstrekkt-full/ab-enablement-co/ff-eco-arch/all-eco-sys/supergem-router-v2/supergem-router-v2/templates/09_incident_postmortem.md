# Template 9: Incident Postmortem (Root Cause + Action Items)

## COPY/PASTE INPUT BLOCK

```
GOAL:
Turn the incident notes I provide into a blameless postmortem with clear root cause, contributing factors, and corrective actions.

CONTEXT:
- System: web/app/backend stack
- Need operational learning + prevention

CONSTRAINTS:
- No blame language; focus on systems
- Include short-term mitigations + long-term fixes

INPUTS:
[Paste: timeline, logs snippets, impact metrics, and what changed recently]

OUTPUT NEEDS:
- Markdown
- Sections: Summary; Impact; Timeline; Root cause; Contributing factors; Detection gaps; Action items (owners/ETA); Verification; CLAIMS CHECK

MODE SWITCHES:
- ReasoningEngine=SelfCriticism
- Framework=STAR
- OutputFormat=BLUF
```

## USAGE NOTES

- Paste your incident timeline, log snippets, and impact data
- SelfCriticism produces initial analysis → critiques → refines
- STAR framework (Situation, Task, Action, Result) structures postmortem
- BLUF format puts executive summary first
- Output is blameless and focuses on system improvements
