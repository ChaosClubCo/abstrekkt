How this library works

Model-agnostic by design. Every prompt runs on any frontier LLM (Claude, GPT-4o/5, Gemini 2/3, Grok). Tool tags signal native fit; [BRACKET] placeholders work universally.

  • ⭐ Go-to = battle-tested, ship without modification
  • Tested = works well, light context customization
  • Draft = solid scaffold, expect to refine

Syntax cheatsheet (works across all models)

  • [VARIABLE] — fill-in-the-blank slot
  • {{var}} — programmatic injection (n8n, Make, code)
  • <tag>...</tag> — section delimiter (Claude prefers; others tolerate)
  • ### Heading — markdown structure (universal)
  • Numbered steps — explicit ordering for chain-of-thought

Hallucination guards (in every Go-to prompt)

  • Citation requirements ([SOURCED] vs [GENERATED])
  • "I don't know" permission
  • Self-critique footer (CLAIMS / COUNTEREXAMPLES / CONTRADICTIONS)
  • Output format anchors (JSON schemas, fixed sections)

Stack-it-yourself patterns

  • Persona + Schema + Self-Eval → API design, code review
  • CoT + Grounding + Citations → research, analysis
  • Modular + Format-Transform + Tone-Control → content production
  • Few-Shot + RTF + Output-Validator → transformations
