**Last Updated:** December 2025

## TL;DR

**Gemini for Workspace** integrates AI directly into **Gmail, Docs, Sheets, Slides, Drive, Meet, Chat, and Vids**. Features include **"Help me write"**, **data analysis in Sheets**, **presentation generation**, **meeting summaries**, and **100+ third-party extensions**. Available on **Business, Enterprise, and Education** plans (January 2025+ included by default).

## Platform Overview

### What is Gemini for Workspace?

Gemini for Workspace is **Google's AI assistant** embedded in:
- **Gmail** → Draft emails, summarize threads, smart replies
- **Docs** → Generate drafts, rewrite content, proofread
- **Sheets** → Analyze data, create formulas, build charts
- **Slides** → Generate presentations, design slides, create images
- **Drive** → Search files, summarize documents, organize folders
- **Meet** → Live captions, meeting notes, action items
- **Chat** → Conversational AI, task automation, app integration
- **Vids** → Script writing, video generation, editing

**Pricing:**
- **Included:** Google Workspace Business, Enterprise, Education (Jan 2025+)
- **Add-on:** $20/user/month (legacy plans)
- **Free trial:** 14 days for Business/Enterprise

## Gmail Integration

### Core Features

**1. Help Me Write**
- **Draft emails** from prompts ("Write a follow-up email thanking John for the meeting")
- **Refine tone** (formal, casual, concise, elaborate)
- **Fancify/shorten** existing drafts
- **Translate** to 100+ languages

**Example Workflow:**
1. Click "Help me write" in Gmail compose
2. Enter prompt: "Decline meeting politely, suggest next week"
3. Gemini generates draft
4. Refine → Select tone (formal), regenerate
5. Insert into email

**2. Summarize Emails**
- **One-click summaries** of long email threads
- **Extract action items** (tasks, deadlines, decisions)
- **Identify key contacts** (who's involved, their roles)

**Example:**
- 47-email thread → 3-paragraph summary + 5 action items

**3. Smart Reply**
- **Context-aware suggestions** (Accept, Decline, Thank, Question)
- **Personalized** based on writing style
- **Mobile-optimized** (quick responses on the go)

**4. Search & Organize**
- **Natural language search** ("Find emails from Sarah about Q4 budget")
- **Auto-categorize** (Promotions, Social, Updates, Forums)
- **Suggest labels** based on content

### Gmail Settings

**Enable Gemini in Gmail:**
1. Open Gmail → Settings (gear icon) → See all settings
2. Click "Gemini" tab
3. Toggle "Help me write" ON
4. Toggle "Smart replies" ON
5. Save changes

**Privacy Controls:**
- **Opt-out of training:** Settings → Data & privacy → Disable "Use my data to improve Gemini"
- **Delete history:** My Activity → Gemini → Delete

## Best Practices

### Effective Prompts

**Gmail:**
- ✅ "Write a polite decline for meeting, suggest next week"
- ❌ "Write an email" (too vague)

**Docs:**
- ✅ "Summarize this 10-page report in 3 bullet points"
- ❌ "Make this better" (unclear improvement)

**Sheets:**
- ✅ "Create a pivot table showing sales by region and product"
- ❌ "Analyze data" (what kind of analysis?)

**Slides:**
- ✅ "Generate 5-slide pitch deck: problem, solution, market, team, ask"
- ❌ "Make a presentation" (no structure specified)

### Privacy & Security

1. **Don't paste sensitive data** (SSNs, credit cards, passwords)
2. **Use DLP rules** (IT admins: block PII in prompts)
3. **Opt out of training** (Settings → Data & privacy → Disable)
4. **Review audit logs** (monthly, check for anomalies)
5. **Train employees** (acceptable use policy, examples)

### Performance Tips

1. **Be specific** (clear instructions → better results)
2. **Iterate prompts** (refine based on outputs)
3. **Use examples** (show Gemini what "good" looks like)
4. **Leverage context** (reference existing docs, data)
5. **Combine tools** (Sheets data → Slides presentation)

## Troubleshooting

### Common Issues

**Issue:** Gemini not showing in Gmail/Docs sidebar  
**Fix:** Check Workspace plan (Business Standard+), enable in Settings → Gemini

**Issue:** "Content blocked" error  
**Fix:** Rephrase prompt (avoid policy violations), adjust safety settings

**Issue:** Slow responses in Sheets (large datasets)  
**Fix:** Use Gemini 3 Flash (faster), reduce dataset size, or batch process

**Issue:** Extension not syncing with third-party app (e.g., Asana)  
**Fix:** Re-authorize connection, check API quota, verify permissions

**Issue:** Audio Overview not generating (NotebookLM)  
**Fix:** Upload at least 2 sources, ensure sources have sufficient content (>500 words)
