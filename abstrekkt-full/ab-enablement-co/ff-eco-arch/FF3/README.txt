QUICK START (15 MINUTES)
-------------------------
1. Add accessibility-styles.css to your <style> section
2. Add accessibility-module.js to beginning of app.js
3. Add skip link to <body>: <a href="#main-content" class="skip-link">Skip to main content</a>
4. Change <div class="header"> to <header class="header" role="banner">
5. Change <div class="main-content"> to <main id="main-content" class="main-content">

TEST IT
-------
- Press Tab key - skip link should appear
- Navigate with keyboard only
- Check browser console for "✓ Accessibility features initialized"
