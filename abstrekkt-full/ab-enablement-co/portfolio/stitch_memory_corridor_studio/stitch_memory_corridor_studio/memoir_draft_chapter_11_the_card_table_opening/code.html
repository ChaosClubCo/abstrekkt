Chapter 11: The Card Table

The table is a card table. Not a desk. Not a standing workstation with cable management. A card table—the kind that folds in half and leans against a wall when company comes.

On it right now: two monitors, an RGB keyboard I didn't need but bought anyway, a Toshiba remote for a TV I can't see, a yellow highlighter, and cables that go places I've stopped tracking. This is the command center. This is where everything gets built.

I built Bear's website here. Bear is Soaring Bear—the man my mother sent me to when everything else had failed. I went to Sedona because I had told myself: 'I've tried at the bottom and I'm still down in this fucking hole. I was wrong about those being the answer, let's try the opposite because I seriously have nothing fucking left.'
