# Incident Response Runbook

    _Generated: 2026-06-21. Reconstruction confidence is bounded by accessible project memory/context and the current chat session._


1. Triage severity and affected tenant/data.
2. Disable compromised endpoint or key.
3. Preserve logs and audit events.
4. Rotate secrets if exposure is possible.
5. Notify affected stakeholders according to policy.
6. Patch and test.
7. Write post-incident review.
