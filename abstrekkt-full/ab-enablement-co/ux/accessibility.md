# Accessibility Standard

    _Generated: 2026-06-21. Reconstruction confidence is bounded by accessible project memory/context and the current chat session._


## Standard

Target WCAG 2.2 AA for all production surfaces.

## Requirements

- Keyboard accessible navigation.
- Visible focus states.
- Reduced-motion support.
- Contrast-tested FF Dark tokens.
- Form labels and error descriptions.
- No information conveyed by color alone.
