What changed from v2
  • Memoir mode now carries the real spine: diagnostic instinct (rooms → processes → systems → music by shape), Construction-not-Recovery, prosthetics-not-productivity, Amen data (99th/12th), letter-to-Kinsley frame.
  • Voice governance is enforced: the banned list — no epiphanies, no "looking back," no "and that's when I realized," no recovery-arc framing — is in the prompt, not just in your head.
  • Memory gaps are protected: "I don't remember" is a valid answer that gets marked MEMORY GAP, never papered over. Emotional truth and factual truth get labeled separately.
  • Confirmation-state discipline: the log now tracks discussed / planned / executed so a session idea never silently becomes "done."
  • Kinsley test added to memoir synthesis: would a 20-year-old understand what this cost?
Claims · Counterexample · Contradictions

Claims: v3 is grounded in project CANON (memoir-explorer, evidence-board, editorial-framework, kyle_docs), so Memoir mode now behaves like your excavation protocol instead of a generic journaling prompt.

Contradictions: Loading this much canon into the paste-prompt risks the tool doing the excavation's thinking for you. Your own protocol says the excavator surfaces material and never imposes resolution — a heavy prompt can drift toward leading. Watch for Claude finishing your sentences; if it does, thin the prompt.
