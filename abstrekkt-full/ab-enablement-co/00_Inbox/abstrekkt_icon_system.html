Hard rules vs. FlashFusion and CC: No gradients. No glow. No blur. No color variants beyond brass/ink/dim.
Border-radius: 4px (not 12px / 8px). Fonts: Fraunces + Crimson Pro + JetBrains Mono — never Geist, never Inter.
Glyph box: two variants only — brass (primary actions/features) · ink (secondary/nav).
If it glows, it's the wrong brand. If it has a gradient, it's the wrong brand.

Tier 2 · Bare stroke
Inline markers · section headers
No container. Brass for primary, ink-mid for secondary, dim for decorative. Single color, no mixing within a section.
No Tier 3
No neon. No glow. No gradient.
Reading Room at Midnight is earned authority. The brass is the only accent the page needs. A second color is always wrong here.
