Starting a New Chat vs. Resuming

ℹ
Claude has no memory between conversations by default. If you resume an old chat, Claude has the full context of that thread. If you start a new one, it starts blank — unless you have memory enabled in settings, which stores lightweight summaries across sessions.
ActionWhen to UseGUI Path

Writing Your First Message

The first message sets the context frame for the entire conversation. Claude infers your role, goal, and tone from it and maintains those assumptions unless corrected.

✓
Effective first messages include: what you're trying to accomplish, any relevant constraints, the format you want, and what you don't want. Vague openers get vague responses and cost you a follow-up turn.
✗
Weak openers: "Help me with X" with no context, "Can you..." questions that force Claude to guess scope, or pasting a wall of text with no instruction attached.

You don't need to be perfect — but the first message is cheaper to get right than fixing drift at message 8.

Mid-Chat Controls

These three actions appear below every Claude response. They do different things — knowing which to use saves a wasted turn.

ControlWhat it DoesUse it When
⟳ Regenerate Re-runs Claude's response to your exact same last message from the same context Response was bad but your question was right — want a different attempt
📋 Copy Copies response text to clipboard Taking output somewhere else
👍 / 👎 Sends feedback to Anthropic. Does not affect your current conversation. Reporting quality issues, not fixing your session
✏ Edit (on your message) Modifies a prior message and re-generates from that point — this is branching Your question was wrong, or you want to try a different direction
⚠
Regenerate ≠ Branch. Regenerate retries from the same message. Edit creates a fork. If you edit message 4, messages 5–N on the original path are preserved — you can navigate back to them. Regenerate replaces the response permanently.

Recognizing Drift

Context drift is when Claude's responses start diverging from your original intent — usually because a long conversation has diluted the original constraints, or because a correction in message 6 introduced a conflicting assumption.

Drift Indicators
!
Claude forgets earlier constraints
You said "no bullet points" in message 2. By message 10 they're back. The instruction is still in context but got deprioritized.
!
Responses get generically correct but context-wrong
Answers are technically fine but no longer specific to your setup, stack, or use case. Claude is pattern-matching on the latest messages, not anchoring on the original brief.
!
Tone or format shifts
Started professional, now it's casual. Or the length has doubled. These are signs the context anchor has loosened.
✓
Fix drift in-thread with a reset message: "Ignore format drift — revert to [original constraint]. Continue from where we were." If it's severe, go back and branch from the last clean message.

Branching
What it is, how to trigger it in the GUI, and when it's the right call versus a cheaper option.

What Branching Is

Branching forks the conversation at any prior message. The original path is preserved. The new path diverges from that point. You can navigate between them.

Conversation Structure After a Branch
You: msg 1 → Claude: resp 1 → You: msg 2 → Claude: resp 2 → You: msg 3 ✏ ← EDIT HERE
Branch A — Original
You: msg 3 (old)
Claude: resp 3
… continues
Branch B — New (active)
You: msg 3 (edited)
Claude: resp 3 (new)
… new direction

Both paths exist. You navigate with arrow indicators that appear near the edited message. Nothing is lost.

How to Branch — Step by Step

1
Hover over one of your messages
As you hover, a small icon row appears above or beside the message bubble. You'll see edit, copy, and sometimes a thumbs down.
2
Click the pencil / edit icon
✏ Edit message
The message text becomes editable inline. The rest of the thread below it goes semi-transparent — it will be replaced when you submit.
3
Modify the message (or not) and send
You can make a tiny change or rewrite it completely. Hit Enter or the send button. Claude generates a fresh response from that point on.
4
Navigate between branches
Arrow indicators appear beside your edited message:
‹ 2 / 2 ›
Click the arrows to switch between Branch A (original) and Branch B (new). The thread below updates to reflect whichever branch is active.

When to Branch vs. Other Options

SituationBest MoveWhy
Wrong assumption in your message 3, conversation went off track BRANCH Correcting mid-stream is cleaner than re-explaining in a new message and fighting accumulated context
You want to try prompt A vs prompt B and compare BRANCH Only way to run parallel paths from the same anchor point
Good conversation state, want to explore a risky direction BRANCH Preserves the clean state; don't corrupt the main thread
Claude gave a bad response but your question was correct REGENERATE Cheaper — retry from same message, don't need a new path
Conversation is fine, just adding context or asking a follow-up FOLLOW-UP No fork needed; just continue the thread
Conversation is fundamentally broken or topic is unrelated NEW CHAT Clean context is cheaper than navigating a broken thread
Minor drift — Claude forgot a formatting rule FOLLOW-UP A correction message fixes it; branching is overkill
ℹ
The signal for branching: you find yourself thinking "I wish I had said X instead of Y back there." That's exactly the problem it solves. Any other situation — use a cheaper tool.

Wrapping up a conversation, extracting output, and deciding what comes next.

Wrapping Up a Conversation

Conversations don't have a formal close state in Claude — you just stop. But there are intentional wrap-up moves that save time later.

1
Request a summary if the thread is long
Ask Claude: "Summarize the decisions made in this conversation and the current state of the output." Paste that into your next session if you're continuing work. This fights the cold-start cost.
2
Copy outputs before closing
Use the Copy button on each response you need. Claude's history persists on claude.ai, but don't assume it's a reliable external store — copy to Notion, a doc, or wherever the output lives.
3
Decide if you're done or continuing
If the work continues, bookmark mentally where you left off. The conversation title in the sidebar defaults to the first message — rename it (click the title) to something meaningful so you can find it later.
