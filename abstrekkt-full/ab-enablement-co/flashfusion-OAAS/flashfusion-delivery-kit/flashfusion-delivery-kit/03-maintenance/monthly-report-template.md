## How to fill this out

1. Log into Facebook Ads Manager at business.facebook.com
2. Set date range to last full calendar month
3. Set columns to: Performance (impressions, reach, clicks, leads, amount spent)
4. Copy numbers into the table below
5. Open Google Sheet CRM and count leads by status
6. Fill in the summary and notes sections

Takes about 20–30 minutes. File it on the first Monday of every month.
