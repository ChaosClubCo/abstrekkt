# Challenge Types Reference

<type_definitions>

## Learning

**Best for:** Courses, books, skills acquisition, certifications

**Check-in questions:**
- What did you learn today?
- Any aha moments or key insights?
- Progress on milestones?
- What's still confusing?
- Resources used?

**Preferences fields:**
- Topics/subjects
- Resources (books, courses, platforms)
- Learning tools (IDE, notebooks, apps)
- Learning style (hands-on, reading, video)
- Practice approach (exercises, projects, quizzes)
- Milestones (chapter counts, module completion)

**Metrics tracked:**
- Sessions completed
- Topics covered
- Resources consumed
- Milestones hit

</type_definitions>

<type_definitions>

## Building

**Best for:** Projects, shipping products, side projects, open source

**Check-in questions:**
- What did you ship today?
- Any blockers or technical challenges?
- Tech stack decisions made?
- What's the next milestone?
- Any scope changes?

**Preferences fields:**
- Project name and description
- Tech stack
- Development tools
- Deployment target
- MVP definition
- Milestones (features, releases)

**Metrics tracked:**
- Features shipped
- PRs/commits
- Blockers resolved
- Milestones completed

</type_definitions>

<type_definitions>

## Fitness

**Best for:** Workouts, health goals, training programs

**Check-in questions:**
- What workout/exercises did you do?
- How did your body feel?
- Any PRs or progress?
- Energy level (1-10)?
- Any injuries or constraints to note?

**Preferences fields:**
- Focus area (strength, cardio, flexibility, sport-specific)
- Equipment available
- Workout types/split
- Location (gym, home, outdoors)
- Best workout times
- Rest days
- Constraints/injuries

**Metrics tracked:**
- Workouts completed
- PRs set
- Rest days taken
- Consistency percentage

</type_definitions>

<type_definitions>

## Creative

**Best for:** Art, writing, music, design, content creation

**Check-in questions:**
- What did you create today?
- Any creative breakthroughs or inspiration?
- Did you reach flow state?
- What medium/tools did you use?
- Satisfied with the output (1-10)?

**Preferences fields:**
- Medium (writing, visual art, music, video)
- Tools/software
- Style or genre
- Publishing platform (if any)
- Inspiration sources
- Daily target (words, minutes, pieces)

**Metrics tracked:**
- Pieces created
- Flow state sessions
- Published/shared items
- Creative hours

</type_definitions>

<type_definitions>

## Habit

**Best for:** Routines, consistency goals, behavior change

**Check-in questions:**
- Did you complete the habit today?
- How did it feel?
- What time did you do it?
- Any resistance or friction?
- Streak status?

**Preferences fields:**
- Habit description
- Trigger/cue
- Reward
- Best time of day
- Accountability method
- Minimum viable version (for hard days)

**Metrics tracked:**
- Completion rate
- Current streak
- Longest streak
- Average time of completion

</type_definitions>

<type_definitions>

## Custom

**Best for:** Anything that doesn't fit other categories

**Check-in questions:** (User-defined during setup)
- Question 1
- Question 2
- Question 3
- Additional notes?

**Preferences fields:** (User-defined during setup)
- User specifies what to track

**Metrics tracked:**
- Sessions logged
- Custom metrics (user-defined)

</type_definitions>

<cadence_options>

## Challenge Cadence

| Cadence | Grace Period | Best For |
|---------|--------------|----------|
| daily | 1 day | Habits, learning sprints |
| every-2-days | 2 days | Sustainable building |
| every-3-days | 3 days | Creative projects |
| weekly | 7 days | Reading, long-form creative |

**Grace period:** How long before a streak breaks. Prevents one bad day from destroying momentum.

</cadence_options>

<compound_learning>

## Cross-Challenge Detection Patterns

**Direct connection:** Challenge A skill enables Challenge B task
- Example: "Learn Rust" → "Build CLI Tools" (same tech)

**Supporting connection:** Challenge A improves Challenge B outcomes
- Example: Morning workout → Coding productivity (energy)

**Temporal correlation:** Success patterns across time
- Example: Journaling + meditation both done = better building sessions

**Detection approach:** Compare topics, tools, timing, and outcomes across challenges to surface connections.

</compound_learning>
