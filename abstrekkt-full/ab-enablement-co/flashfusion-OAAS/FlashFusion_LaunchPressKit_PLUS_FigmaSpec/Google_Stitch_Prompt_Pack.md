# Google Stitch Prompt Pack (FlashFusion Brand)
Stitch generates UI from text prompts and supports iterative refinement and Figma export (Standard mode). Use screen-by-screen prompting and lock style + tokens.

## Global Style Block (prepend to every prompt)
- Brand: FlashFusion
- Dark-first UI, background #0f0618, text #f3e8ff
- Accents: primary #a855f7, secondary #f472b6
- Glass panels with blur, subtle glow on focus/hover
- Typography: Poppins headings, Inter body
- Accessibility: WCAG AA contrast, clear focus ring, large tap targets
- Layout: 8px grid, generous spacing, premium minimal

## Prompt 1 — Landing / Home (Web)
Create a responsive web landing page for FlashFusion (AI workflow orchestration for creators).
Sections: top nav, hero, feature grid (6), demo panel (placeholder), testimonials (3), pricing (3 tiers), FAQ, footer.
Use dark-first glassmorphism, neon accents only on CTAs. No lorem ipsum; use concise real copy.

## Prompt 2 — App Shell (Web)
Create the main app shell: left sidebar (collapsed/expanded), topbar, main canvas area, right inspector panel.
Include a “Workflow Builder” page layout with node canvas placeholder, properties panel, and run logs panel.
Glass surfaces with subtle borders; focus rings in purple.

## Prompt 3 — Auth (Mobile)
Design mobile login + sign up screens for FlashFusion with a premium dark glass background.
Include email/password, SSO buttons, forgot password, and password rules helper.
Use strong contrast and clear error states.

## Prompt 4 — Dashboard (Web)
Design a dashboard home: stats row (4), recent projects table, quick actions, and notifications panel.
Include empty states that feel premium and helpful.

## Prompt 5 — Workflow Builder (Web)
Design a workflow canvas screen: node library drawer, canvas, node inspector, run controls, timeline, logs.
Show the “two streams fusing” motif subtly in the background.

## Prompt 6 — Billing (Web)
Design billing settings: plan cards, payment method, invoices table, usage meters, and upgrade CTA.
Make usage meters readable and WCAG AA compliant.

## Prompt 7 — Settings (Web)
Design settings with tabs: Profile, Team, Security, Integrations, Tokens.
Include MFA setup and API key management table.

## Prompt 8 — Iteration Prompt (use after any output)
Refine: tighten spacing, increase contrast for small text, reduce visual noise, ensure CTAs use primary purple, ensure glass borders are subtle and consistent, and align typography to Poppins/Inter scale.
