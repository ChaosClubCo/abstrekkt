# FlashFusion Launch/Press Kit Pack

## What’s inside
- /figma: component library spec + naming system
- /prompts: UI image prompt library + Google Stitch prompt packs
- /press-kit: press release, fact sheet, media kit guidance, SVG logo mark

## How to use
1) Run Stitch prompts to generate UI screens, then “copy to Figma”.
2) Apply Figma naming system and publish components.
3) Export screenshots + social sizes.
4) Use press release + fact sheet for announcements.

## Notes
All assets are aligned to FlashFusion’s dark-first glassmorphism aesthetic and neon brand anchors.
