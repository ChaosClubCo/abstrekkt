# Launch Checklist (1 week)

## T-7 to T-4
- Finalize brand kit + tokens + drift guard
- Prepare press kit + screenshots
- Create Product Hunt assets
- Set up onboarding + email sequences

## T-3 to T-1
- Smoke test critical flows (auth, dashboard, builder, billing)
- Accessibility pass (axe + manual spot checks)
- Performance sanity (LCP/CLS)
- Warm up audience (teasers)

## Launch Day
- Publish announcement
- Open waitlist / signup
- Ship PH post + socials
- Monitor errors + feedback loop

## Post-launch (72 hours)
- Fix top bugs
- Publish changelog
- Book user interviews
