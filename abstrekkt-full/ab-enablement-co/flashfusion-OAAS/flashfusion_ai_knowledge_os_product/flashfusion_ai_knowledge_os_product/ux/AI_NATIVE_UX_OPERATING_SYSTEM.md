# AI-Native UX Operating System

## Purpose

AI-native UX must help humans understand probabilistic, agentic, provenance-aware systems.

## Core UX Modes

### Explore

Browse entities, assets, memory, relationships, and timelines.

### Trust

Inspect provenance, confidence, source lineage, and contradictions.

### Act

Approve recommendations, trigger workflows, assign agents, update memory.

### Review

Audit agent runs, prompt changes, migrations, and relationship drift.

### Compress

Convert complexity into a focused operator brief.

## Required UI States

Every major view must support:

- loading
- empty
- partial data
- degraded
- permission denied
- stale
- conflicted
- unresolved
- AI uncertain
- offline
- success
- error

## Core Screens

1. Executive Overview
2. Memory Map
3. Asset Graph
4. Entity Explorer
5. PromptOps Registry
6. Agent Control Center
7. Provenance Inspector
8. Drift Dashboard
9. Decision Queue
10. Cognitive Compression Brief

## Design Principle

The UI must never make uncertain AI output look more certain than it is.
