# Provenance Overlays

## Purpose

Provenance overlays let users inspect where data came from without leaving workflow context.

## Overlay Components

- Source summary
- Original source link/path
- Ingested timestamp
- Last modified timestamp
- Extracted by
- Transformed by
- Confidence score
- Related entities
- Relationship lineage
- Agent usage history

## UX Pattern

Every entity detail view should support a "Why do we know this?" interaction.

## Overlay States

- source available
- source missing
- source stale
- source contradicted
- source low confidence
- source generated by AI
- source manually validated
