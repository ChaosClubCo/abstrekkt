# Human Cognitive Protection

## Purpose

The system must protect operators from overload, fragmentation, and architecture sprawl.

## Risks

- context overload
- too many projects
- too many prompts
- duplicate memory
- unresolved decisions
- unclear priority
- agent noise
- artifact sprawl
- stale workflows

## Protection Mechanisms

### Executive Compression Brief

A daily or on-demand summary of:

- active priorities
- unresolved decisions
- stale knowledge
- conflicting memory
- agent failures
- next best actions

### Decision Queue

All proposed major actions enter a queue with:

- reason
- impact
- confidence
- source
- risk
- recommended action

### Focus Mode

Limits visible context to:

- one project
- one objective
- one next action
- relevant assets only

### Entropy Alerts

Alerts when:

- duplicate assets grow
- unresolved references increase
- prompt versions diverge
- agent tasks stall
- stale memory dominates
