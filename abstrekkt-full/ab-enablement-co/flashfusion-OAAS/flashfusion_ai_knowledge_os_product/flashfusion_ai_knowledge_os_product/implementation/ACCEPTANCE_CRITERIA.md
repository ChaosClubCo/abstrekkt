# Acceptance Criteria

## Product Acceptance

The package is accepted when it can serve as the source of truth for building the FlashFusion AI-Native Knowledge OS.

## Architecture Acceptance

- Constitution exists.
- Canonical ontology exists.
- Entity taxonomy exists.
- Relationship semantics exist.
- Temporal semantics exist.
- Governance policies exist.
- Memory hierarchy exists.
- Agent routing exists.
- UX operating system exists.
- Observability model exists.

## Engineering Acceptance

- SQL schema exists.
- RLS starter policies exist.
- TypeScript contracts exist.
- JSON schemas exist.
- seed examples exist.
- build prompt exists.
- audit prompt exists.

## Governance Acceptance

- PromptOps lifecycle defined.
- Agent permissions defined.
- Tenant isolation defined.
- Base44 migration rules defined.
- Schema evolution policy defined.
- Mutation safety defined.

## UX Acceptance

- uncertainty UI defined.
- provenance overlay defined.
- degraded states defined.
- cognitive protection model defined.

## CLAIMS CHECK

This package provides a complete blueprint and scaffold. It is not a substitute for implementation, testing, deployment, or legal/security review.
