08 — Governance
Usage Rules

These are constraints, not suggestions. Violations break the brand.

✓ Do
Use --ff-void or --ff-deep as all backgrounds
Use --ff-primary only for large UI fills (buttons, feature art)
Text hierarchy: text → text-muted → primary-light → electric-light
Gate heavy WebGL / Three.js behind device capability checks
Use --ff-glow exclusively for decorative luminance
All motion must represent cause → effect, not decoration
Focus rings: 2px solid --ff-electric-light, offset 3px
Use Poppins 800+ for display, Inter for body copy
✗ Don't
Use pure #FFFFFF anywhere in the palette
Use --ff-primary as body text (fails AA at small sizes)
Use --ff-glow as a button fill — reserved for glow only
Add particle spam or bloom-heavy effects without restraint
Use violet text under 14px on --ff-void (contrast failure)
Use purple-to-pink gradients on white backgrounds — ever
Use --ff-electric as dominant color — accent only
Use Arial, Roboto, or system-ui as primary font
