# Figma AI Make Prompts

This document contains prompts for Figma’s AI Make tool, covering
each phase of the FlashFusion orchestration strategy as well as the
immediate priorities. Copy and paste the relevant prompt into
Figma Make to generate wireframes, diagrams, boards or dashboards
tailored to your project plan.

## Phase 1 – Business Intelligence Layer

Design three persona cards (Solo Creator, Development Team and
Enterprise Client) summarizing pain points, workflows, devices and
success metrics, plus a pricing page wireframe for Starter ($29),
Pro ($79) and Enterprise tiers with feature lists and call‑to‑action
buttons.

## Phase 2 – Technical Architecture Matrix

Create a responsive UI kit for a React 18 + TypeScript SaaS
dashboard using Tailwind CSS v4 and a system architecture diagram
showing Supabase edge functions, the Hono web server, key‑value
store, real‑time channels and multi‑region deployment with CDN,
load balancers, monitoring and Sentry.

## Phase 3 – Design/Dev Coordination Framework

Generate a design system overview (color tokens, typography,
spacing, icons, components) with annotations for weekly syncs and
audits, plus a two‑week sprint board with columns for design review,
implementation, testing, QA and deployment and tasks reflecting
your workflow.

## Phase 4 – Quality Gates & Success Metrics

Produce a quality dashboard with gauges for accessibility (WCAG 2.1 AA),
performance (<3 s load), visual consistency and mobile optimization (<2 s),
and a KPI dashboard showing MAU, conversion rate, NPS, feature adoption,
uptime, API p95 response time, error rate and performance score.

## Phase 5 – Critical Risk Mitigation

Design a compliance checklist interface covering SOC 2 Type II, GDPR,
HIPAA, CCPA requirements (data encryption, user consent, audit logs,
incident response), plus a scalability planning board with tasks for
database tuning, CDN optimization, auto‑scaling, monitoring and
capacity planning.

## Phase 6 – Team Structure & Coordination

Create an org chart for the core SaaS team (Product Manager,
Frontend Engineers, Backend Engineers, DevOps Engineer, UI/UX
Designer, QA Engineer, Data Analyst) with placeholders for extended
roles, and a calendar view showing daily stand‑ups, weekly syncs,
bi‑weekly sprint events, monthly all‑hands and quarterly OKR reviews.

## Phase 7 – Implementation Roadmap

Generate a timeline broken into discovery (requirements, architecture
audit, team setup, timeline creation, monitoring setup), development
(foundation setup, feature development, optimization), QA (device
testing, benchmarking, penetration tests, UAT, load tests) and launch
(staged deployment, marketing, onboarding improvements, real‑time
monitoring and post‑launch optimization).

## Phase 8 – Blindspot Mitigation

Design a risk matrix board categorizing blindspots—technical debt,
user experience gaps, performance under load, security vulnerabilities,
market competition—and pair each with mitigation strategies such as
refactoring sprints, regular user testing, load testing, security
audits and competitive analyses.

## Priority 1 – Foundation (Days 1–2)

Create a to‑do list interface for defining scalability targets (user
volumes and MRR growth), clarifying compliance requirements (SOC 2,
GDPR, HIPAA), establishing team roles and setting up comprehensive
monitoring (Sentry, DataDog). Tasks should be checkable.

## Priority 2 – Quality Gates (Days 3–5)

Generate a Kanban board with tasks to implement an automated testing
pipeline, set up performance budgets and monitoring, create security
scanning automation and establish code review and deployment
processes. Use To Do, In Progress and Done columns.

## Priority 3 – Success Metrics (Days 6–7)

Design an analytics dashboard with tasks to define and implement
tracking (events and dashboards), create a business metrics dashboard
(MAU, MRR, NPS, churn), set up a user feedback collection system
(surveys, NPS) and establish an A/B testing framework. Represent
tasks as cards with checkboxes.
