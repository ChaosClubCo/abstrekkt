# Support Escalation Guide

> **Audience:** CUST | **Phase:** Beta

---

## How to Report Issues

**Step 1:** Determine severity

| Severity | Examples | Response Time (Growth) |
|----------|---------|----------------------|
| **Critical** | All workflows stopped, data loss risk, security concern | 1 hour |
| **High** | Specific workflow broken, connector down, approvals stuck | 4 hours |
| **Medium** | Slow performance, intermittent errors, dashboard issue | 8 hours |
| **Low** | Question, feature request, documentation gap | 24 hours |

**Step 2:** Contact support

| Channel | How | Best For |
|---------|-----|----------|
| Slack (#ops-autopilot-support) | Post message with severity + description | Fastest for Critical/High |
| Email (support@opsautopilot.com) | Include: severity, workflow, error message, screenshots | All severities |
| Dashboard (Support tab) | Click "Report Issue" → fill form | Medium/Low, with auto-attached logs |

**Step 3:** Include these details
- Severity level
- Which workflow is affected
- Error message (screenshot or copy-paste)
- When it started
- How many users affected
- Steps to reproduce (if known)

## What Happens After You Report

1. **Acknowledgment** within response time SLA
2. **Diagnosis** — support engineer reviews logs and dashboard
3. **Update** — you'll hear back with findings or questions
4. **Resolution** — fix deployed, verified working
5. **Confirmation** — we confirm with you that issue is resolved

## If You Don't Hear Back

- Response time elapsed with no acknowledgment? Escalate:
  - Slack: tag `@int-engineering-lead`
  - Email: cc `escalations@opsautopilot.com`
- Still no response after 30 minutes? Call your dedicated success manager (Enterprise) or email INT VP Engineering directly (contact provided during onboarding)
