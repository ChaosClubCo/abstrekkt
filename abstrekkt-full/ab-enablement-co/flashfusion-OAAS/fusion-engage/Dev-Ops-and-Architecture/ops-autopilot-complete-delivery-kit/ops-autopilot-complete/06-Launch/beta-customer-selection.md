# Beta Customer Selection Criteria

> **Audience:** SALES, LEAD | **Phase:** Beta (Week 5)

---

## Must-Have Criteria

- [ ] US-based (timezone alignment for support)
- [ ] 100–500 employees
- [ ] At least 1 full-time IT staff member
- [ ] Uses Azure AD or Okta for identity
- [ ] Uses Slack or Teams for communication
- [ ] Losing 10+ hours/week to manual IT ops (self-reported)
- [ ] Comfortable with Docker/basic infrastructure
- [ ] Willing to provide weekly feedback (30-min call)
- [ ] Willing to be a reference customer if satisfied
- [ ] Decision-maker can commit within 1 week

## Nice-to-Have

- [ ] Uses Jira or ServiceNow for ticketing
- [ ] Compliance requirements (SOC2, HIPAA) — validates audit features
- [ ] 200+ employees (higher workflow volume = better testing)
- [ ] Previous automation experience (faster onboarding)
- [ ] Active in tech community (word-of-mouth potential)

## Disqualification Criteria

- On-prem only (no cloud infrastructure) — n8n needs Docker
- <50 employees — insufficient workflow volume
- No IT staff — can't manage n8n instance
- Budget approval >30 days — too slow for beta timeline
- Competitor evaluation in progress — split attention

## Sourcing Channels

1. Existing INT client base (warm leads)
2. LinkedIn outreach to IT Directors at target companies
3. HumanX conference contacts
4. Tech community referrals
5. Subreddit communities (r/sysadmin, r/msp)
