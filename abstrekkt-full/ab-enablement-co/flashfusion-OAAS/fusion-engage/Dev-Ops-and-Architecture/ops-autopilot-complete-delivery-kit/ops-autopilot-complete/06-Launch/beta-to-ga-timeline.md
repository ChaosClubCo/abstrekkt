# Beta to GA Timeline

> **Audience:** ALL | **Phase:** Beta/RC

---

## Closed Beta (Weeks 5–8)

**Week 5:** First 5 customers onboarded, daily support standups, Offboarding workflow dev starts
**Week 6:** Offboarding ready for testing, first customer feedback batch, bug fixes
**Week 7:** Customers 6–10 onboarded, License + VPN workflows start, first NPS survey
**Week 8:** License + VPN code complete, load test (10 customers × 3 workflows), retrospective

**Exit Criteria:** NPS >40, <5% churn, 3+ workflows active per Growth customer, security audit prep started

## Open Beta (Weeks 9–12)

**Week 9:** Open signup, customers 11–20, performance optimization (P95: 8s→5s)
**Week 10:** License + VPN live for all, Security Incident workflow code complete
**Week 11:** All 7 workflows live, customers 21–30, 100 concurrent test
**Week 12:** Retrospective, pricing refined, GA planning, sales deck drafted

**Exit Criteria:** 30+ customers, $8K MRR, documentation complete, sales team trained

## Release Candidate (Weeks 13–16)

**Week 13:** GA date announced, beta renewals, 3 case studies written
**Week 14:** Bug fixes only (code freeze), sales training, support training
**Week 15:** Final security audit, 1000 concurrent load test, Go/No-Go meeting
**Week 16:** Final prep, soft launch, press release, customer webinar

**Exit Criteria:** All GA readiness gates passed (see checklist)

## GA Launch (Week 17+)

**Week 17:** Full launch — self-service signup enabled, marketing activated, PR published
**Week 18–20:** Daily war room (first 2 weeks), monitor closely, rapid response to issues
