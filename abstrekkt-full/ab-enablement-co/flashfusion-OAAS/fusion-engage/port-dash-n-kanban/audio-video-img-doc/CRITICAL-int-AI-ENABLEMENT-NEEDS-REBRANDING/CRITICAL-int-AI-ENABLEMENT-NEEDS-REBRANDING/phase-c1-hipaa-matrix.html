📋 Tier Definitions
Tier 1 Healthcare Ready — BAA available, HIPAA compliant, recommended for PHI
Tier 2 BAA Required — Compliant with proper agreements, review before PHI use
Tier 3 Not Recommended — Missing critical controls, do not use with PHI
🔒 HIPAA Technical Safeguards Checklist
  • Access Control (§164.312(a)): Unique user IDs, automatic logoff, encryption/decryption
  • Audit Controls (§164.312(b)): Hardware, software, procedural mechanisms to record and examine access
  • Integrity Controls (§164.312(c)): Policies/procedures to protect ePHI from improper alteration or destruction
  • Transmission Security (§164.312(e)): Technical measures to guard against unauthorized access during transmission
  • Authentication (§164.312(d)): Procedures to verify person or entity seeking access is who they claim
⚠️ Implementation Requirements
  • BAA Execution: Must be signed before any PHI processing. INT provides template BAAs.
  • Data Classification: All data must be classified before AI processing. PHI requires Tier 1 platforms.
  • Minimum Necessary: Only minimum PHI required for task should be exposed to AI systems.
  • De-identification: Where possible, use Safe Harbor or Expert Determination de-identification.
  • Training: All users accessing AI systems with PHI must complete HIPAA training.
