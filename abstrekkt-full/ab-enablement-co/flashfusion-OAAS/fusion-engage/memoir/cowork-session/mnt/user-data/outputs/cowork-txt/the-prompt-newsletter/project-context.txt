Last updated: April 11, 2026

## What this project is
Weekly AI newsletter for technical practitioners. Publishes Thursday. Research → Brief → Draft → Edit → Deliver.

## Hard constraints
1. Never fabricate statistics — T1/T2 sources only (Anthropic, OpenAI, arXiv, MIT TR, Bloomberg Tech, etc.)
2. Never reproduce copyrighted text — paraphrase with attribution, no block quotes
3. Never reference employer
4. Never repeat a topic covered in the last 8 weeks — check TEMPLATES/topic-log.md first
5. Never use T3 sources (Reddit, Twitter, personal blogs) as citations

## What never to write here
- "AI is changing everything" without a specific, citable claim
- Beginner explainers — assume practitioner audience
- Stats that only appear in T3 sources
- Any of the banned words in anti-ai.md
