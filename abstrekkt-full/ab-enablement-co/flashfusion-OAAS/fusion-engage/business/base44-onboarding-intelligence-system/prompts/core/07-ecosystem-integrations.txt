[BASE44 PROMPT] Ecosystem Integrations
=======================================
Atomic, self-contained. Paste into app.base44.

You are designing the INTEGRATIONS layer for a deal-sourcing / portfolio app. Goal:
connect the app to the user's existing stack so data flows in/out without manual work.

Targets (see /integrations for per-service guides): Supabase (data + RLS), Vercel
(hosting/edge), n8n (workflow automation), Microsoft (M365/Power Platform), Claude
(AI features), Google (Workspace/Drive), AWS (storage/compute).

Generate logic that:
1. Presents an integrations catalog filtered by the user's stated stack.
2. For each, defines: auth method, data direction (in/out/bi), synced entities,
   and failure handling (retry, backoff, surfaced error).
3. Lets users connect/disconnect and shows last-sync status + health.
4. Emits a normalized event when external data lands (so analytics stays consistent).

Requirements:
- Emit events: integration_connected{service}, sync_succeeded{service},
  sync_failed{service,reason}, integration_disconnected{service}.
- Never store third-party secrets in plain client state; broker server-side.
- Rate-limit + backoff on every outbound call.

--- IMPLEMENTATION NOTES ---
- Treat all inbound external data as untrusted; validate before persisting.
- This prompt references, but does not duplicate, the per-service /integrations guides.
