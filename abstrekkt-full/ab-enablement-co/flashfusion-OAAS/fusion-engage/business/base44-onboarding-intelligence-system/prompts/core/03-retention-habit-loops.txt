[BASE44 PROMPT] Retention & Habit Loops
========================================
Atomic, self-contained. Paste into app.base44.

You are designing the RETENTION layer for a deal-sourcing / portfolio app. Goal:
build a recurring habit loop (trigger -> action -> variable reward -> investment)
so users return without being pushed.

Generate logic that:
1. Defines the core habit per outcome type:
   - find_deals -> daily/weekly "new matched deals" digest.
   - track_portfolio -> periodic portfolio movement + alert summary.
   - join_community -> activity from followed people/syndicates.
2. Picks an optimal cadence per user from observed engagement (not fixed spam).
3. Delivers a variable reward (sometimes a standout deal/insight) to keep it fresh.
4. Adds an "investment" step each visit (save a filter, follow a market) that makes
   the next session more valuable.
5. Detects decay (declining opens/sessions) and adapts cadence down before churn.

Requirements:
- Emit events: habit_trigger_sent, habit_action_completed, reward_shown,
  investment_made, retention_decay_detected.
- Respect a frequency cap; let users tune cadence.
- Read lifecycle_state to avoid colliding with activation or expansion messaging.

--- IMPLEMENTATION NOTES ---
- Variable reward must be genuine (a real standout deal), not artificial gamification.
- Decay detection feeds the Lifecycle Intelligence prompt's stage transitions.
