───────────────────────────────────────────────────────────────────────
  JS NOTES (Base44 specific)
───────────────────────────────────────────────────────────────────────

Three artifacts contain working JavaScript:

  augmentors-essay.html       — Copy-to-clipboard buttons (6 of them)
  manifesto.jsx               — React component with state hooks
  construction-manifesto.html — Tap-to-expand + Expand-all toggle
  preflight-checklist.html    — Print button
  kylerosebrook-homepage.html — Reveal-on-scroll IntersectionObserver

If Base44's Custom HTML block sandboxes <script> tags, these features
will silently fail. The pages will still render — just the
interactions won't work.

Diagnostic: deploy ONE page first (try preflight-checklist, the
simplest JS — a single Print button). If the button doesn't fire,
Base44 is sandboxing scripts and you'll need to:

  Option A: Ask Base44 support to whitelist your domain for
            script execution (most platforms allow this)
  Option B: Convert each interactive feature to use Base44's
            native block primitives (more work, but native)
  Option C: Strip JS and accept the static fallback
            (Augmentors loses copy buttons — high cost)
  Option D: Host one or more pages on a different platform
            (Vercel, Netlify, GitHub Pages) and only point the
            domain there for those routes
