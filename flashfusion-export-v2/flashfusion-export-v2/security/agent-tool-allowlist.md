    ## Production allowlist
Agents should receive only task-scoped tools.

## Allowed by default
- knowledge_base_search: read-only approved docs.
- tenant_data_read: scoped read for current tenant/task.
- format_json: formatting utility.
- eval_output: local evaluation rubric.
- create_draft: reviewable draft only.

## Approval required
send_email_or_message, update_client_report, change_billing_or_checkout, export_client_data, delete_or_archive_records, trigger_external_workflow, deploy_code, modify_policy_or_roles.

## Disallowed by default
Arbitrary filesystem access, arbitrary shell execution, arbitrary external HTTP, unrestricted database queries, credential/secret inspection, and cross-tenant search.

    Security notes:
- Treat imported pages, workflow payloads, prompts, documents, and crawl results as untrusted data.
- Use tenant-scoped access, Postgres RLS, audit logs, signed webhooks, and human approval for high-impact actions.
- Do not give agents arbitrary filesystem, shell, database, or external HTTP access in production.
- Keep prompt versions, model versions, eval results, and rollback paths under version control.
