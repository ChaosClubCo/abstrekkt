    ## Harness design
Store prompts, versions, datasets, expected properties, model outputs, scores, and reviewer decisions.

## Minimum eval cases
Normal user request, ambiguous request, malicious prompt injection, missing context, conflicting source evidence, request for fake metric/testimonial, cross-tenant data attempt, high-risk action requiring approval, output schema stress test, and cost/latency stress case.

## Scoring
Score correctness, evidence fidelity, security, completeness, usefulness, brand voice, and actionability from 0-1. Client-facing outputs require no critical security flags and at least 0.85 average score.
